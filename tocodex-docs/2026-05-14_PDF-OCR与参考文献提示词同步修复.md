# PDF OCR、参考文献提示词与 Git 同步规则修复

## 摘要
- 将 PDF 兜底 OCR 从旧的 PaddleOCR jobs 接口改为 AIStudio 官方 `layout-parsing` 接口：使用 base64 JSON 请求、`Authorization: token ...` 鉴权，并读取 `result.layoutParsingResults[].markdown.text`。
- 修复参考文献生成未真正读取全局提示词的问题：`_build_manuscript_part_prompt()` 的参考文献分支现在读取 `PromptService.load_global_prompt("manuscript_references")`，全局提示词编辑后会参与实际生成。
- 更新 `.env.example` 中 PaddleOCR 配置项，改为 `PADDLEOCR_AISTUDIO_LAYOUT_URL`。
- 完善根目录 `.gitignore`：只屏蔽 Python 缓存、虚拟环境、构建产物、日志、前端依赖、可重建索引和 ToCodex 本地进度；明确不屏蔽 `.env`、`*.env`、`config/`、`prompts/`、`projects/`、`*.key`、`*.pem` 等配置/密钥/项目文件，保证这些文件修改后可以随 GitHub 和服务器同步。
- 将已跟踪的缓存类文件从 Git 索引移除：`.tocodex/progress/`、`libriscribe/src/libriscribe/rag/__pycache__/`、`libriscribe/src/libriscribe/web/__pycache__/`。这些文件仍保留在本地，但以后不会干扰同步。
- 已运行语法检查：`python -m py_compile libriscribe\src\libriscribe\rag\document_loader.py libriscribe\src\libriscribe\web\app.py`，通过。
