# 章节写作专著模式修复

## 摘要
- 修复全章生成时目录结构错乱：不再先集中输出所有二级结构标题，而是按 `1.1 -> 1.1.1/1.1.2 -> 1.2 -> 1.2.1...` 的目录顺序生成。
- UI 写作计划去掉“目标多少字 / 已写多少字 / pending / 结构标题”等工程化展示，改为更接近正常专著写作工作台的状态显示。
- 写作提示词去掉对目标字数的显式强调，要求模型不要在正文里输出“目标字数/已写字数”等后台规划信息。
- 增加模型异常输出清理：如果第三方 API 返回 HTML 网页、错误页或 `HubLinuxDO` 之类内容，不再写入章节正文，而是标记为生成失败提示。

## 变更文件
- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 按目录顺序输出结构标题和叶子小节正文。
  - 从 prompt 中移除目标字数字段。
  - 新增 `_sanitize_model_output()` 过滤 HTML/错误页输出。
- `libriscribe/src/libriscribe/web/app.py`
  - 写作单元列表移除目标字数指标和 pending/结构标题标签。
  - 展示改为“待写作 / 已完成 / 生成异常”和可选已生成字数。
- `libriscribe/prompts/templates/chapter_writer.yml`
  - 改写字数要求为正常专著模式，禁止输出后台字数规划和 HTML/网页代码。

## 验证
- 已运行：`python -m py_compile libriscribe/src/libriscribe/agents/chapter_writer.py libriscribe/src/libriscribe/web/app.py`，通过。
