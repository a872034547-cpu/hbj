# 章节生成 Errno 22 路径写入修复

## 摘要

修复用户在章节生成时遇到的 `生成失败：[Errno 22] Invalid argument`。本次定位到问题更可能来自 Windows 文件系统路径/文件名写入阶段，而不是模型、API Base 或网络本身。

## 关键修复

1. 新增章节输出路径统一构造与预检：
   - 清理项目目录中误带的外层引号。
   - 校验章节号必须是正整数。
   - 小节临时文件名保留中文与 Unicode 字母数字，同时替换 Windows 不安全字符。
   - 生成前创建并验证项目目录/输出目录可写。
2. 实时生成与后台生成统一复用同一套路径构造逻辑，避免行为不一致。
3. `write_markdown_file()` 不再静默吞掉写入失败，而是记录日志后向上抛出可读 `OSError`。
4. UI 错误提示区分文件系统错误与模型/API 错误，避免把路径问题误导为模型配置问题。
5. 新增回归测试覆盖路径清理、小节文件名清理、非法章节号和文件系统错误提示。
6. 已重启 Streamlit 应用进程。
