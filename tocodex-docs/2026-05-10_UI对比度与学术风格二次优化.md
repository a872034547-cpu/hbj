# UI 对比度与学术风格二次优化

## 摘要

根据反馈，已对全局 UI 进行二次优化：降低强 AI / 科技渐变风格，提升文字与背景对比度，并修复侧边栏顶部残留白背景和图标显示异常问题。

## 主要变化

- 将强蓝紫/青色光斑与高饱和渐变移除，改为低饱和米白纸张网格背景。
- 提高主内容卡片背景不透明度，减少玻璃透明导致的阅读对比度不足。
- 将按钮从强渐变改为克制的墨绿实体按钮。
- 将进度条、指标卡强调线等由科技渐变改为墨绿/金棕低饱和色。
- 取消侧边栏标题渐变文字，避免 emoji / 图标被 `background-clip: text` 影响显示。
- 同时覆盖 `stSidebar`、`stSidebarContent`、内部 wrapper 和 section 背景，修复左侧界面顶部白背景残留。
- 输入框、表单、标签页、聊天消息等区域提高背景实度与文字可读性。
