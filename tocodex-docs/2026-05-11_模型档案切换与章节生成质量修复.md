# 模型档案切换与章节生成质量修复

## 摘要

本次修复聚焦模型配置页状态绑定、章节正文预览污染、大纲小节编辑能力，以及长文生成字数偏差和正文质量偏差。

主要调整：

- 模型档案编辑表单改为按当前选择的档案生成动态 `key`，避免 Streamlit 复用旧字段值导致切换模型后配置和提示不刷新。
- 章节生成不再把章摘要、大纲树、写作思路直接拼接为“本章导语”写入正文；这些内容仅作为 AI 写作上下文进入提示词。
- 大纲章节管理中的小节从只读展示升级为可编辑，可修改小节标题、写作目标/写作思路和目标字数。
- 章节写作提示词新增“正文输出边界”约束，禁止输出“本章导语”“写作思路”“资料依据”“证据边界”等规划标签。
- 收紧章节生成与质量重写的 token 预算，并对明显超出目标字数的小节增加压缩步骤，降低长文过写导致的字数偏差。
- 增加回归测试覆盖以上行为。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 修复模型档案切换后的表单状态绑定。
  - 增加大纲小节编辑 UI 与保存逻辑。
- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 移除正文中自动拼接“本章导语”的生成路径。
  - 增加正文输出边界提示词。
  - 收紧生成 token 预算。
  - 增加超长正文压缩逻辑。
- `libriscribe/tests/test_commercial_routes.py`
  - 新增模型档案动态 key 回归测试。
  - 新增大纲小节编辑入口回归测试。
  - 新增章节正文不泄漏大纲/写作思路回归测试。
  - 新增提示词正文边界和超长压缩回归测试。
