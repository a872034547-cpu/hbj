# 资料页指标按钮修复与证据片段删除

## 日期
2026-05-11

## 问题
用户反馈资料来源页四个指标按钮点击后无反应：
- "资料来源" / "证据片段" → JS 滚动无效（Streamlit iframe 沙箱限制）
- 证据片段缺少删除按钮

## 修复内容

### 1. 替换 broken JS scroll 机制
- **文件**: `libriscribe/src/libriscribe/web/app.py` (行 4744-4763)
- 移除 `st.components.v1.html` + `getElementById` + `scrollIntoView`（在 Streamlit 沙箱 iframe 中完全无效）
- 改用 `st.session_state["sources_focus_docs"]` / `st.session_state["sources_focus_evidence"]` 标记
- 在目标区域（"已索引资料" / "证据片段样例"）用 `st.info()` 显示醒目标记引导用户

### 2. 新增证据片段删除功能
- **文件**: `libriscribe/src/libriscribe/web/app.py`
- 新增 `_delete_evidence_chunk_from_project()` helper（行 5555-5567），删除单条证据片段
- 每个证据片段 expander 内新增"删除此证据片段"按钮

### 3. 引用页跳转验证
- "引用记录" / "未核验引用" 通过 `st.session_state["current_page"] = "Citations"` + `st.rerun()` 跳转
- `PAGE_RENDERERS["Citations"]` → `render_citations_page` 映射正确，无需修改

### 4. 测试更新
- **文件**: `libriscribe/tests/test_commercial_routes.py`
- 更新 `test_sources_page_metric_buttons_are_clickable_for_management` 匹配新 session_state 标记
- 新增 `test_delete_evidence_chunk_removes_single_chunk_only` 测试
- 全部 65 测试通过

- `libriscribe/src/libriscribe/web/app.py` — 替换 scroll 机制 + 新增 helper + 删除按钮
