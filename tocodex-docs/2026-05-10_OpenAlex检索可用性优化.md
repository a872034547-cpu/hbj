# OpenAlex 检索可用性优化

## 摘要

用户反馈 OpenAlex 检索提示“返回结果不足或缺少刊名/年份/标题”，本次排查确认根因是 OpenAlex Works API 的文献 `type` 字段实际返回 `article`，而不是 Crossref 风格的 `journal-article`。旧过滤条件 `type:journal-article` 会把中文期刊论文结果过滤为空。

## 实际排查结果

以关键词 `智慧工地 建筑技术 2025` 和用户提供的 API Key 调试：

- `filter=type:journal-article`：OpenAlex 返回 0 条。
- 不加 type 过滤：OpenAlex 返回 1 条，类型为 `article`。
- `filter=type:article`：OpenAlex 返回 1 条，包含标题、年份、刊名和页码，可生成引用。

可用候选示例：

- 标题：建筑工程的施工技术及其现场的施工管理的探讨
- 年份：2025
- 类型：article
- 刊名：建筑工程与管理
- 卷期页码：7(5):41-41
- DOI：10.33142/aem.v7i5.16798

## 变更文件

- `libriscribe/src/libriscribe/services/literature_search_service.py`
  - 将 OpenAlex 期刊论文过滤从 `type:journal-article` 改为 `type:article`。
  - 新增 `search_with_diagnostics()`，返回候选数量、OpenAlex meta、候选列表、剔除原因和隐藏密钥后的请求 URL。
  - 新增 `citation_missing_reasons()`，明确说明候选无法生成引用的原因，例如缺少标题、刊名或年份。
  - 保留 `search()` 与 `fetch_and_format_citations()` 对外接口兼容。
- `libriscribe/src/libriscribe/web/app.py`
  - 资料页 OpenAlex 区域改为使用诊断检索。
  - 检索后显示 OpenAlex 总命中数、当前页候选数。
  - 增加“查看 OpenAlex 原始候选与不可用原因”面板，用户可直接看到标题、年份、刊名、类型、DOI 和剔除原因。
  - 增加提示说明：OpenAlex 的期刊论文类型应使用 `article`，不是 `journal-article`。
- `libriscribe/tests/test_outline_pipeline_services.py`
  - 更新测试断言，覆盖 `type:article` 过滤和字段完整性诊断。
