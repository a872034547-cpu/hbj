# 大纲前资料头脑风暴接入

## 摘要

本次在第二步资料页新增“大纲前头脑风暴”能力：AI 可基于项目描述、联网检索词、OpenAlex 候选、搜索 API 网页结果、参考文献核查线索、项目引用记录和已上传证据片段，生成专著结构化头脑风暴。生成结果会保存到项目数据中，并在后续大纲生成、分章生成、单章修改和二次改进时作为优先上下文使用。

## 变更文件

- `libriscribe/src/libriscribe/knowledge_base.py`
  - 为 `ProjectKnowledgeBase` 新增 `outline_brainstorm` 持久化字段。
- `libriscribe/src/libriscribe/web/app.py`
  - 在资料页 AI 资料助手中新增“大纲前头脑风暴”任务。
  - 增加项目引用记录上下文，并扩大头脑风暴任务可使用的证据片段数量。
  - 生成头脑风暴后自动保存到项目，并提供可编辑、保存、清空入口。
  - 新增 `_outline_brainstorm_context()`，让大纲生成读取已保存头脑风暴。
  - 将头脑风暴注入全书大纲约束、分章架构提示、分章小节提示和单章修改提示。
- `libriscribe/tests/test_commercial_routes.py`
  - 增加测试，验证头脑风暴可持久化并进入大纲约束。
