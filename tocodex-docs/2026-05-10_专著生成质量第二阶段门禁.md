# 专著生成质量第二阶段门禁实施备忘录

## 摘要

本次完成第二阶段专著生成质量门禁：在第一阶段“导出稿清洁度检查”的基础上，新增面向正文生成质量的静态体检能力，并接入审校与质量中心。该阶段不改变生成主流程、不强制阻断导出，而是在审校页明确提示专著正文是否存在内容深度不足、疑似伪引用、无来源事实句、非学术语体和长章节结构缺失等风险。

## 主要变更

- 新增 `QualityService.manuscript_quality_report()`，用于生成专著正文质量报告。
- 增加内容深度检查：识别段落平均信息量偏低、专著论证维度不足等问题。
- 增加结构风险检查：识别较长章节缺少小节标题结构的情况。
- 增加伪引用检查：识别项目无引用记录却出现 `[数字]` 引用、引用编号超出现有引用数量，以及未绑定来源的“已有研究表明”等表述。
- 增加无来源事实句检查：在缺少已核验引用时，提示年份断言、百分比/数据断言、法规标准断言和机构报告断言风险。
- 增加专著语体检查：识别第一人称、营销化表达、过度主观表达和占位残留。
- 审校与质量中心新增“正文质量”指标、“正文生成质量风险”表格和原始 JSON 报告。
- 增加回归测试覆盖风险稿识别和含已核验引用的高质量稿通过。

## 说明

当前第二阶段属于“审校提示型门禁”，不会自动删除或重写正文，避免误伤用户已经生成的内容。后续第三阶段建议把该报告进一步接入章节生成循环：当小节出现伪引用、明显短文、无来源数据断言或语体风险时，自动触发一次定向重写，并把重写前后的质量报告保存到章节评审记录中。
