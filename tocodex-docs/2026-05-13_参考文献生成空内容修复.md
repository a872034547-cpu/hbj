# 参考文献生成空内容修复

## 摘要
修复“参考文献生成提示成功但没有内容”的问题。原因包括：模型接口超时/504 时未能返回正文，以及参考文献字段读取时漏取 `formatted_ref`，导致已导入引用记录没有进入提示词上下文。

## 变更内容
- 参考文献上下文读取时补充 `formatted_ref` 字段，确保引用管理中已导入的参考文献能进入生成上下文。
- 增加参考文献有效条目检测，避免只有“参考文献”标题也被当作成功结果保存。
- 当模型接口超时或返回空内容时，若项目已有 citation 或资料库来源，则自动生成兜底参考文献列表并保存，避免空内容。
- 下调参考文献生成请求的 token 和超时参数，减少接口 504/超时概率。
