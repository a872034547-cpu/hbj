# UI 米白玻璃风与刷新闪屏修复

## 摘要
- 将 Streamlit 主界面从深色风格恢复为米白/奶油色玻璃拟态视觉系统。
- 侧边栏导航改为悬浮玻璃胶囊样式，并增加 hover 悬浮提示，弱化原先偏 AI 化的图标表达。
- 调整 Streamlit 主题配置为浅色米白配色，降低首次加载时的白屏/旧样式突兀感。
- 移除后台任务区域的 HTML `meta refresh` 整页刷新，避免刷新时浏览器先闪出旧首页或 Streamlit 默认骨架。
- 清理主要导航和核心 i18n 文案中的 AI/emoji 化表达。
- 已执行语法检查：`python -m py_compile libriscribe/src/libriscribe/web/app.py libriscribe/src/libriscribe/web/i18n.py`，通过。
- 追加修复：移除 `sys.stdout.buffer` 手动包装逻辑，避免 Streamlit 热重载时出现 `ValueError: I/O operation on closed file`。
- 追加修复：隐藏 Streamlit 自动发现的多页面导航，避免启动时短暂显示 `app / chat / dashboard / editor / outline / settings` 英文目录。
- 彻底处理：将 `src/libriscribe/web/pages` 目录重命名为 `src/libriscribe/web/legacy_pages`，从源头阻止 Streamlit 把旧页面识别为多页面应用。

## 变更文件
- `libriscribe/src/libriscribe/web/app.py`
  - 全局 CSS 更新为米白悬浮玻璃风。
  - 删除后台任务 `meta http-equiv="refresh"` 整页刷新逻辑。
  - 清理部分页面提示中的 AI/emoji 化文案。
  - 修复 Windows 标准输出编码处理，避免关闭流导致页面报错。
  - 增强 CSS 隐藏规则，屏蔽 Streamlit 原生多页面导航闪现。
- `libriscribe/src/libriscribe/web/i18n.py`
  - 更新中英文导航、标题、按钮、提示语，弱化图标和 AI 术语。
- `libriscribe/.streamlit/config.toml`
  - 切换为浅色主题，设置米白背景、浅米色次级背景和墨绿色主色。
- `libriscribe/src/libriscribe/web/__init__.py`
  - 移除旧 `pages.dashboard` 导出，避免引用已迁移的旧页面模块。
- `libriscribe/src/libriscribe/web/legacy_pages/`
  - 原 `pages/` 目录迁移到 `legacy_pages/`，保留旧代码但不再被 Streamlit 自动发现为导航页面。
