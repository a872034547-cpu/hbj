# Tavily 资料补充渠道接入

## 摘要

已将 Tavily 作为资料助手的新增资料补充渠道接入现有流程。资料助手在模型明确不支持联网搜索、或资料库头脑风暴发现仍需补充资料时，会优先调用 Tavily；如果 Tavily 未配置、调用失败或无候选结果，则回退到原百度/搜索 API。所有搜索候选仍遵循既有安全链路：先打开网页抽取正文，再交由 AI 筛选，只有筛选通过的网页材料才保存到资料库和证据片段。

## 变更文件

- `libriscribe/src/libriscribe/settings.py`
  - 增加默认 Tavily API Key，仍可通过 `.env` 或 Web UI 自定义覆盖。

- `libriscribe/src/libriscribe/web/app.py`
  - 改造 `_run_sources_ai_gap_search()`：新增 Tavily 参数，补检链路改为 Tavily 优先、百度/API 兜底。
  - 更新资料助手 UI 文案和提示词护栏，明确 Tavily/百度候选均只能作为待核验资料线索。
  - 将 Web UI 中配置的 Tavily Key、Base URL、返回条数、搜索深度传入自动补检流程。
  - 完善搜索 API 配置区说明，支持用户在 Web 中自定义 Tavily API Key。

- `libriscribe/tests/test_commercial_routes.py`
  - 更新百度兜底回归断言。
  - 新增 Tavily 优先路径测试，验证 Tavily 候选仍需打开网页并通过 AI 筛选后才入库。
