# AI 生成参考文献转圈修复

## 摘要

修复网页中 AI 生成参考文献时遇到模型接口超时、限流、密钥错误或模型名错误后长时间转圈的问题。

本次处理将参考文献生成改为快速失败路径：降低参考文献生成的输出预算，限制自定义 OpenAI-compatible 接口的 raw HTTP 尝试次数和单次请求超时，并把常见接口错误转换为中文可操作提示。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 新增 `_friendly_llm_generation_error()`，识别 401、422、429、504、524、timeout 等常见错误并提示用户检查 API Key、模型名、额度或切换 OpenAlex/资料检索生成真实引用。
  - 调整 `_generate_manuscript_part_with_ai()`：当 `part_key == "references"` 时使用 `max_tokens=2800`、`timeout_seconds=45`、`raw_attempt_limit=2`，避免参考文献生成长时间卡住。
  - 当模型返回空内容且 `client.last_error` 有错误信息时，立即抛出并展示友好错误，不再只显示空结果或持续 spinner。

- `libriscribe/src/libriscribe/utils/llm_client.py`
  - `LLMClient.generate_content()` 新增可选参数 `timeout_seconds` 和 `raw_attempt_limit`。
  - DeepSeek、Mistral 和自定义 OpenAI-compatible raw HTTP 调用支持按调用方传入的超时执行。
  - 自定义 OpenAI-compatible raw HTTP 调用支持限制尝试次数，同时保持默认长文生成路径不变。

- `libriscribe/tests/test_commercial_routes.py`
  - 增加参考文献生成快速失败参数测试。
  - 增加常见模型接口错误友好提示测试。
  - 增加自定义 LLM 客户端快速失败参数测试。
