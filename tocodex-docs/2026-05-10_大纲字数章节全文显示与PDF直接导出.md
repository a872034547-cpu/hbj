# 大纲字数遵循、章节全文显示与 PDF 直接导出修复

## 摘要

本次修复针对用户反馈的三个问题：生成内容没有严格接近大纲字数、章节编辑器只能看到摘要/截断内容、PDF 导出只生成 LaTeX 而不是直接 PDF。

## 主要变化

- 章节写作提示词明确要求按小节大纲字数写作，允许范围为目标字数的 85%—115%。
- 如果模型初稿明显短于目标字数，会自动发起续写补足，直到更接近大纲字数。
- 修复补写后小节 `actual_word_count` 未重新统计的问题。
- 章节编辑器新增「完整预览 / 编辑原文」两种显示方式：
  - 完整预览直接读取 `chapter_N.md` 全文，不再只显示项目摘要。
  - 编辑原文高度提升到 900，可编辑完整 Markdown。
  - 支持下载本章 Markdown 全文。
- PDF 导出改为使用 `PdfExporter` 直接生成 `.pdf` 文件，不再依赖 Pandoc/XeLaTeX，也不再只提示下载 `.tex`。
- 新增 `libriscribe/src/libriscribe/export/pdf_export.py`，使用 `fpdf` 和 Windows 中文字体直接生成 PDF。
