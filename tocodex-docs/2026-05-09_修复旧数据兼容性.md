# 修复旧项目数据兼容性（AttributeError）

## 问题描述
新增的 `Chapter.word_count`、`Chapter.sections`、`ProjectKnowledgeBase.custom_api_base` 等字段在加载旧项目 JSON 时引发 `AttributeError`，因为旧数据中不存在这些字段，且 session_state 缓存了旧模型实例。

## 修复方案（双保险）

### 1. `knowledge_base.py` — 数据迁移
在 `load_from_file()` 中添加迁移逻辑，加载 JSON 后自动补全新字段：
- `custom_api_base`, `custom_api_key`, `custom_model` → 默认空字符串
- 每个 chapter 的 `word_count` → 0, `sections` → []

### 2. `app.py` — 防御性访问 + 自动重载
- 所有读取新字段的地方使用 `getattr(obj, 'attr', default)` 防御性访问
- `init_session_state()` 中检测旧数据（`hasattr(project, 'custom_api_base')`），自动从文件重新加载

## 修改文件
- `libriscribe/src/libriscribe/knowledge_base.py` — `load_from_file()` 迁移逻辑
- `libriscribe/src/libriscribe/web/app.py` — `init_session_state()` 旧数据检测 + `getattr()` 防御性访问（outline 页面、AI 配置页面、LLM 客户端创建）
