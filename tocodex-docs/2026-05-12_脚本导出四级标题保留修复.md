# 脚本导出四级标题保留修复

## 摘要

修复网页“Word（带格式）导出”在把章节 Markdown 转成结构化 JSON 时丢失四级标题层级的问题。此前 `#### （一）/（二）` 会被压平成 `subsections`，导出脚本只能按三级标题处理，导致 Word 中看起来只有三层标题。

现在 Markdown 层级会按专著目录结构保留：

- `#` → 章
- `##` → 节
- `###` → 三级标题 `level3`
- `####` 及更深 → 四级标题 `level4`

同时保留 `subsections` 兼容旧调用方。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 更新 `_markdown_content_to_structured_chapter()`，输出嵌套的 `level3` / `level4` 结构。
  - 兼容旧版 `subsections` 字段。
- `libriscribe/tests/test_commercial_routes.py`
  - 增加带 `#### （一）`、`#### （二）` 的导出适配测试，确保四级正文和标题不会丢失。

## 验证

已运行定向测试：

```cmd
python -m pytest tests\test_commercial_routes.py::test_sidebar_exposes_formatted_word_export_and_structured_adapter tests\test_export_and_quality_gate_services.py::test_structured_json_formatted_word_export_builds_formal_sections -q
```

结果：`2 passed`。
