# 修复 AI 大纲生成、RAG 索引与 PDF 直接导出残留问题

## 摘要

本次修复针对运行时反馈的三个残留问题进行了收尾处理：

1. AI 大纲生成失败：已改为在 Web 端直接调用当前项目选择的模型生成学术专著四级目录，并立即解析为章/节/三级/四级写作单元，避免旧 `OutlinerAgent.execute()` 不返回结果导致误判失败。
2. RAG 索引失败：修正上传文档索引时对 `VectorStore.add_documents()` 的错误调用，移除不存在的 `metadata=` 参数。文档元数据已由 `DocumentLoader` 写入每个分块。
3. PDF 直接导出 `-1`：在 `pdf.output()` 输出阶段捕获 `KeyError(-1)` 等底层异常，避免 UI 只显示裸露的 `-1`，并返回更明确的中文错误说明。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - `_generate_outline_with_ai()` 改为直接使用当前 `LLMClient` 生成学术专著目录。
  - `_index_rag_documents()` 中 `store.add_documents(chunks, metadata={...})` 改为 `store.add_documents(chunks)`。

- `libriscribe/src/libriscribe/export/pdf_export.py`
  - 对 `pdf.output(str(output))` 增加异常捕获。
  - 将 `KeyError(-1)` 转换为可理解的 PDF 字体/字符映射兼容性提示。
