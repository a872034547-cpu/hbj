# 专著生成质量第五阶段：导出前交付门禁

## 摘要

本阶段把已实现的正文质量检查与导出就绪检查接入“出版与交付中心”，让用户在点击 DOCX / PDF / PPTX / LaTeX 导出按钮之前，先看到最终交付风险。该阶段不阻断导出，避免影响预览稿生成，但会明确提示短章、重复标题、过程残留、伪引用、无来源事实句等高风险问题。

## 主要改动

- 在导出页新增“导出前交付门禁”。
- 导出前自动调用正文收集逻辑 `_collect_chapters()`，确保检查对象与实际导出对象一致。
- 接入 `QualityService.export_readiness_report()` 显示导出就绪分数、章节数、总字数和导出风险。
- 接入 `QualityService.manuscript_quality_report()` 显示正文质量分数和正文质量风险。
- 高风险问题存在时展示醒目提示，引导用户先到“审校”页处理。
- 保留导出按钮，支持继续导出预览稿或阶段稿。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - `render_exports_page()` 新增导出前质量门禁区域。
  - 在导出按钮区域前展示导出就绪、正文质量、章节数、总字数。
  - 展示“导出就绪风险”和“正文质量风险”明细表。
- `libriscribe/tests/test_commercial_routes.py`
  - 新增导出页交付门禁回归测试，确保导出页调用导出就绪报告和正文质量报告，并且门禁展示位于交付文件按钮之前。
