# 用户说明书：资料库、资料索引 API 与写作流程配置教程

## 1. 这个版本能做什么

本版本把写书流程拆成两条互不干扰的配置线：

1. **模型档案**：用于大纲生成、正文写作、润色、资料助手等文本生成任务。
2. **资料索引 API 配置**：只用于上传资料时建立向量索引，调用服务商的 `/embeddings` 接口。

同时，本版本补充了资料库和引用库的基础管理能力：

- 上传后的资料来源支持查看详情。
- 每条资料可查看关联证据片段。
- 不需要的资料支持删除，删除时会同步移除该资料对应的证据片段。
- 资料页已移除依赖 Tavily 的“AI 文献核查闭环”板块，避免未安装 Tavily 时干扰用户。
- OpenAlex 生成并导入的引用直接进入已核验引用记录，不再要求二次核验。
- 引用文献支持用户手动自定义添加。
- 引用记录支持在页面查看详情和删除。
- 手动添加的引用默认标记为“未核验”，便于后续 DOI、URL、数据库或原文核查。

即使不配置资料索引 API，资料上传仍会进入资料库，大纲和正文仍能读取资料片段；资料索引只是增强检索能力，不再强制下载 HuggingFace 本地模型。

## 2. 启动系统

在项目目录运行：

```bash
cd libriscribe
python -m streamlit run src\libriscribe\web\app.py
```

如果已有服务运行在其他端口，也可以指定端口：

```bash
cd libriscribe
python -m streamlit run src\libriscribe\web\app.py --server.port 8503
```

浏览器打开 Streamlit 提示的本地地址即可。

## 3. 配置正文写作模型

进入侧边栏的 **模型设置** 页面，在 **模型档案** 区域填写：

- **档案名称**：例如“DeepSeek 正文写作”或“自定义 GPT”。
- **平台类型**：选择 OpenAI、DeepSeek、OpenRouter 或自定义平台。
- **模型名称**：填写用于写大纲/正文的聊天模型名。
- **API Base**：官方平台通常可留空；自定义平台通常填写到 `/v1`。
- **API Key**：服务商控制台提供的密钥。
- **启用此模型**：勾选后项目可选择使用。

保存后可在 **在线状态检测** 中测试模型是否可用。

> 注意：模型档案只负责文本生成，不负责资料向量索引。

## 4. 单独配置资料索引 API

仍在 **模型设置** 页面，向下找到单独的 **资料索引 API 配置** 区域。

这里和上面的模型档案互不影响，保存到独立配置文件：

- `libriscribe/config/material_index_api.json`

需要填写：

- **启用资料向量索引 API**：需要向量索引时打开。
- **资料索引 API Base**：例如 `https://api.deepseek.com/v1`。
- **资料索引模型**：必须是服务商支持 embeddings 的模型，例如 `DeepSeek-V4-Flash`。
- **资料索引 API Key**：填写 embeddings 接口可用的密钥。

保存后，上传资料时勾选“同时建立向量索引”，系统会使用这个独立配置建立索引。

## 5. DeepSeek 资料索引示例

配置示例：

- 资料索引 API Base：`https://api.deepseek.com/v1`
- 资料索引模型：`DeepSeek-V4-Flash`
- 资料索引 API Key：填写你自己的 DeepSeek API Key
- 勾选：启用资料向量索引 API

不要把 API Key 粘贴到提示词、文档正文、说明书或代码里。

## 6. 上传资料要求

资料页支持上传：

- PDF：可复制文本型 PDF 效果最好；扫描件需要先 OCR。
- DOCX：推荐 Word 文档格式。
- TXT / Markdown：推荐 UTF-8 编码。
- HTML / HTM：网页摘录。
- XLSX / XLS：表格资料。

暂不推荐直接上传旧版 `.doc` 二进制文档；请先另存为 `.docx`、`.pdf` 或 `.txt`。

无法解析的常见原因：

- PDF 是扫描图片，没有文字层。
- 文件加密、损坏或扩展名与真实格式不一致。
- 旧版 `.doc` 文件含 OLE 二进制结构。
- 文本严重乱码，系统会拒绝入库以避免污染资料库。

## 7. 如何证明资料已经入库

在 **资料与检索 / 上传资料** 中选择文件后，点击 **导入资料库**。

导入成功后页面会显示：

- 资料文件名
- 资料 ID
- 证据片段数量
- 向量块数量
- 当前状态：资料库模式或已建立向量索引
- 后续用途：大纲生成、正文写作和引用参考都会读取该资料

如果未勾选向量索引，状态会显示“资料库模式”，这不是失败；资料仍可被大纲和正文引用。

## 8. 查看和删除资料

进入 **资料与检索** 页面，找到 **已索引资料** 区域。

每条资料会显示：

- 标题或文件名
- 资料 ID
- 文件路径或文件名
- 证据片段数量
- 入库状态
- 入库时间和文件 hash（如有）

点击 **查看资料详情与片段**，可以查看：

- 资料标题
- 文件名或文件路径
- 资料类型
- 入库状态
- 入库时间
- DOI / URL（如有）
- 摘要或首段
- 关联证据片段预览

点击 **删除资料** 后，系统会删除：

1. 该条资料来源记录。
2. 该资料对应的证据片段。

删除资料不会自动删除已经人工整理过的引用记录。这样做是为了避免误删用户已经确认、编辑或用于交付的参考文献信息。

## 9. OpenAlex 引用导入

进入 **资料与检索** 页面，打开 **OpenAlex 学术文献自动检索与引用生成**。

可按项目主题、章节标题、关键词或 DOI 检索文献。生成参考文献后点击 **导入到引用记录**，系统会把这些 OpenAlex 引用保存到项目引用库。

本版本处理规则：

- OpenAlex 导入记录默认状态为“已核验”。
- 不再要求进入“AI 文献核查闭环”做二次审核。
- 用户仍可在引用页面查看详情、删除或补充 DOI / URL。
- 依赖 Tavily 的独立文献核查板块已经移除。

## 10. 自定义添加引用文献

进入 **引用与事实核验中心** 页面，打开 **自定义添加一条引用文献**。

可填写：

- 题名
- 作者（多个作者可用逗号、分号或顿号分隔）
- 年份
- 期刊 / 出版社 / 网站 / 来源
- DOI（可选）
- URL（可选）
- GB/T 7714 格式参考文献（可选）

如果填写了完整的 GB/T 7714 格式参考文献，系统会优先保存该完整文本。
如果没有填写完整参考文献，系统会根据题名、作者、来源和年份自动拼接一条基础格式。

手动添加后，该引用会进入引用库，并默认标记为：

- 状态：未核验
- 置信度：0
- 来源：用户手动添加

后续可在核验入口中补充 DOI、URL 或页码，并点击人工确认已核验。

## 11. 查看和删除引用记录

进入 **引用与事实核验中心** 页面，找到 **引用记录管理**。

每条引用会显示：

- 引用 ID
- 来源
- 当前状态
- 格式化参考文献
- DOI / URL
- 页码或定位
- 置信度
- 元数据

点击 **查看引用详情** 可以展开完整信息。点击 **删除引用** 可移除该条引用记录。删除引用不会删除资料库中的来源文档或证据片段。

## 12. 如何证明正文生成引用了资料库

进入 **正文编辑** 页面生成章节或小节前，系统会显示资料库可用性证明，包括：

- 本次写作提交给 AI 的资料来源文件名
- `evidence_id`
- 资料片段预览

生成完成后还会显示“生成完成资料引用证明”。用户可根据 `evidence_id` 回到资料库核对来源。

## 13. 推荐使用流程

1. 在 **模型设置** 配置正文写作模型。
2. 在 **资料索引 API 配置** 单独配置 embeddings 接口；不需要向量索引时可先不启用。
3. 创建或打开项目。
4. 到资料页上传文档，先确认“资料已入库”反馈。
5. 在 **已索引资料** 中查看资料详情和证据片段，确认资料可读、可用。
6. 如发现错误资料，可点击 **删除资料** 清理。
7. 在 **资料与检索** 使用 OpenAlex 检索并导入引用记录；OpenAlex 记录默认已核验。
8. 在 **引用与事实核验中心** 粘贴参考文献，或使用 **自定义添加一条引用文献** 手动补充引用。
9. 在 **引用记录管理** 中查看、删除或补充引用。
10. 生成或优化大纲。
11. 到正文编辑页逐章/逐小节生成，确认页面显示资料库调用证明。
12. 最后到引用、质量和导出页面检查并交付。

## 14. 常见问题

### 不配置资料索引 API 能不能写书？

可以。资料会以“资料库模式”进入项目，大纲和正文仍会读取资料片段。

### 资料索引 API 和模型档案能用不同服务商吗？

可以。正文写作可以用一个模型，资料索引可以用另一个 embeddings 服务商。

### 为什么不再默认下载 HuggingFace？

为了避免网络超时导致用户上传失败。现在上传资料优先保障入库，向量索引作为可选增强。

### 上传成功但向量块为 0 是失败吗？

不是。向量块为 0 表示未建立向量索引或索引失败，但证据片段已经进入资料库，仍可用于大纲和正文参考。

### 删除资料后引用记录为什么还在？

引用记录可能已经被用户手动整理、核验或用于交付。删除资料只删除资料来源和证据片段，不自动删除引用库中的人工引用记录。

### 自定义添加的引用为什么是未核验？

系统不能仅凭用户输入或 AI 生成文本判断文献真实存在。手动添加后默认未核验，用户需要通过 DOI、URL、数据库、期刊官网或原文资料进一步确认。

### OpenAlex 导入的引用为什么不再要求核验？

OpenAlex 属于开放学术数据库，本版本把 OpenAlex 检索并格式化导入的记录作为已核验引用处理，以减少用户重复操作。用户仍可在引用记录管理中查看、删除或补充 DOI / URL。

### 为什么看不到 AI 文献核查闭环 / Tavily 配置？

该板块已移除。当前资料页不再暴露依赖 Tavily 的独立文献核查闭环，避免 Tavily 未安装或未配置时造成流程阻塞。
