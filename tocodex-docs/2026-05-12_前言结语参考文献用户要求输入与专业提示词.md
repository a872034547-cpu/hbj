# 前言结语参考文献用户要求输入与专业提示词

## 摘要
- 在写章节页的“专著前后内容与参考文献”区域，为前言、结语、参考文献分别增加用户生成要求输入框。
- 为前言增加预期字数参数，为结语增加预期字数参数，为参考文献增加起止年份、建议数量、语种分布、引用格式等参数。
- 将原有通用提示词替换为前言、结语、参考文献三套专业独立提示词，并把用户输入要求、项目说明、章节核心结论、前言闭环信息、已有引用和资料库上下文注入提示词。
- 更新测试，验证 UI 控件、专用提示词、用户要求和参考文献参数均已接入。

- `libriscribe/src/libriscribe/web/app.py`
