# 资料上传默认免向量索引修复

## 摘要

本次修复针对“上传资料无法上传”的问题：资料上传流程此前默认会初始化 embedding/向量索引，可能触发 HuggingFace 本地模型访问与超时，导致用户资料还未进入资料库就被阻断。

现在上传资料默认只导入资料库并生成证据片段，不主动下载或初始化 HuggingFace embedding 模型。向量索引改为可选项，只有用户勾选“同时建立向量索引”时才会加载 `EmbeddingProvider` 和 `VectorStore`。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - `_index_rag_documents()` 增加 `build_vector_index: bool = False` 参数。
  - 默认上传流程只使用 `DocumentLoader` 导入资料库。
  - 仅在用户勾选向量索引时初始化 embedding 与 Chroma 向量库。
  - 资料页、章节页、设置页上传按钮调整为“导入资料库”。
  - 上传说明明确“默认先导入资料库，不主动下载 HuggingFace embedding 模型”。

- `libriscribe/tests/test_commercial_routes.py`
  - 更新资料上传回归测试，覆盖默认免 embedding、可选向量索引、上传格式和资料库用途标记。
