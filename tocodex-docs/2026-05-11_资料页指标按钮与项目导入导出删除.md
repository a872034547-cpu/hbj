# 资料页可点击指标按钮 + 项目导入导出删除

## 变更概述

### 1. 资料页顶部四个指标卡片改为可点击按钮

用户需求：资料页顶部显示的"资料来源 1 / 证据片段 0 / 引用记录 5 / 未核验引用 5"应能直接点击跳转到对应的管理区域。

实现方案：

- **资料来源** / **证据片段** → 点击后在同页内平滑滚动到"已索引资料"/"证据片段样例"区域
- **引用记录** / **未核验引用** → 点击后跳转到引用管理页（Citations），供用户查看、删除、自定义添加

技术实现：
- 四列 `st.columns(4)` 中的 `st.metric` 替换为 `st.button`，保持样式视觉上类似指标卡片
- 添加 `sources_scroll_to` session_state 变量控制滚动目标
- 使用 `st.components.v1.html` 注入 JavaScript `scrollIntoView`
- 在"已索引资料"和"证据片段样例"前添加 `<div id="..."></div>` HTML anchor

### 2. 加载已有项目页支持导入/导出/删除

用户需求：在"加载已有项目"页支持：
- 导出项目为 zip
- 导入 zip 项目包
- 删除项目（需输入密码 `hbj123`）

新增 helper 函数：
- `PROJECT_DELETE_PASSWORD = "hbj123"`
- `_safe_project_import_name()` — 清理导入项目名为安全目录名
- `_unique_project_dir()` — 避免同名目录覆盖
- `_build_project_export_zip()` — 将项目目录打包为 zip bytes
- `_import_project_zip()` — 从 zip 导入项目，含路径遍历安全检查
- `_delete_project_by_path()` — 按 knowledge_base.json 路径删除项目目录
