# OpenAlex 语义搜索升级

## 摘要

已学习并接入 OpenAlex `search.semantic` 语义搜索能力，用于提升长文本大纲、章节目标、摘要式查询的文献匹配准确度。系统现在支持在 OpenAlex 检索页和大纲文献检索工作流中选择“语义搜索”或“关键词搜索”。

## OpenAlex 语义搜索要点

- API 参数：`search.semantic=<query>`。
- 适合输入章节目标、大纲段落、摘要、研究问题等长文本。
- OpenAlex 最多使用前 2000 字符做语义匹配。
- 可与大多数 `filter`、`select` 参数组合使用。
- 不支持 `cited_by_count` 排序/过滤，因此系统在语义搜索模式下不再传 `sort=cited_by_count:desc`。
- 当前仍保留 `type:article` 和近年 `publication_year` 过滤。

## 变更文件

- `libriscribe/src/libriscribe/services/literature_search_service.py`
  - `search()`、`search_with_diagnostics()`、`build_openalex_search_url()` 支持 `search_mode`。
  - `_openalex_params()` 在 `semantic` 模式下使用 `search.semantic`，并自动截断到 2000 字符。
  - 语义搜索模式下不传 `sort=cited_by_count:desc`。
  - `search_by_outline()` 默认使用语义搜索，适合按大纲含义检索文献。
- `libriscribe/src/libriscribe/web/app.py`
  - OpenAlex 检索区新增“语义搜索 search.semantic / 关键词搜索 search”切换。
  - 语义搜索时提供长文本输入框，默认使用项目标题、描述、大纲组合。
  - 大纲文献检索新增“语义搜索 / 关键词搜索”切换。
  - 页面说明中提示语义搜索限制与适用场景。
- `libriscribe/tests/test_outline_pipeline_services.py`
  - 新增语义搜索 URL 构造断言。
  - 新增语义搜索参数与 API key 脱敏测试。
