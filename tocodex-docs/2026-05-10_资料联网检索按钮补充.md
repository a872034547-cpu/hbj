# 资料联网检索按钮补充

## 摘要

本次根据反馈，为资料页顶部的“资料联网检索词”增加了独立的“检索资料”按钮，避免用户输入关键词后没有明确触发动作。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 将“资料联网检索词”输入框改为输入框 + 按钮布局。
  - 新增“检索资料”按钮。
  - 点击按钮后将检索词保存到 `st.session_state["sources_online_query_submitted"]`。
  - 仅在点击按钮后展示知网/万方/期刊官网/Crossref 等外部核验入口。

## 验证

已通过：

```cmd
python -m compileall src
python -m pytest tests\test_commercial_routes.py -q
```

结果：9 项测试通过。
