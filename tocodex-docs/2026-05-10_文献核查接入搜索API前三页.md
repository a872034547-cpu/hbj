# 文献核查接入搜索 API 前三页

## 摘要

为 AI 文献核查闭环接入通用网页搜索 API，支持按大纲检索和按参考文献题名辅助核查，并将搜索范围限制为前三页。搜索结果作为真实性复核线索展示，不直接替代 OpenAlex/DOI 等结构化核验结论。

## 变更文件

- `libriscribe/src/libriscribe/services/literature_search_service.py`
  - 新增默认搜索 API 地址。
  - 新增 `web_search()`，按页调用接口并合并去重，最多检索前三页。
  - 新增 `web_search_for_references()`，按参考文献解析结果生成检索式并逐条搜索前三页。
  - 新增 `_web_search_params()` 和 `_mask_web_search_url()`，支持 `id/key/words/page/tn/ck/dkey/uip` 参数并隐藏敏感信息。
- `libriscribe/src/libriscribe/web/app.py`
  - 在“AI 文献核查闭环”中新增搜索 API 配置区。
  - 新增“按大纲搜索网页前三页”按钮。
  - 新增“搜索 API 辅助核查前三页”按钮。
  - 新增大纲网页搜索结果和参考文献网页辅助核查结果展示。
  - 修复搜索结果区后的缩进错误。
- `libriscribe/tests/test_outline_pipeline_services.py`
  - 新增搜索 API 参数构造测试。
  - 新增前三页调用与 URL/标题去重测试。
