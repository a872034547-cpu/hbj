# 完成 i18n 语言切换功能

## 日期
2026-05-09

## 概述
为 Libriscribe Web UI 添加了完整的中英文语言切换功能（i18n），默认显示中文。

## 修改文件

### 新增文件
- `libriscribe/src/libriscribe/web/i18n.py` — 国际化模块，包含 ~180 个翻译键的中英文对照

### 修改文件
- `libriscribe/src/libriscribe/web/app.py` — 所有页面渲染函数和辅助函数中的硬编码中文字符串替换为 `t()` 调用

## 功能说明
- 侧边栏顶部新增语言切换下拉框（🌐 界面语言）
- 支持 `简体中文` 和 `English` 两种语言
- 默认语言为中文（zh）
- 语言切换后自动刷新页面（`st.rerun()`）
- 翻译函数 `t(key, **kwargs)` 支持格式化参数，如 `t('chapter_item', n=3)` → "第 3 章"

## 覆盖范围
- 侧边栏（导航、项目信息、导出按钮）
- Dashboard（项目概览、创建表单、加载项目）
- 大纲页面（大纲编辑、章节管理）
- 编辑器页面（章节编辑、AI 写作/评审）
- 聊天页面（AI 助手对话）
- 设置页面（基本信息、术语表、风格指南、RAG 文档、危险操作）
- 所有辅助函数（项目加载/保存/创建/删除、导出、RAG 索引、错误提示）

## 启动方式
```bash
cd libriscribe
streamlit run src/libriscribe/web/app.py --server.port 8501 --server.headless true
```

访问 http://localhost:8501
