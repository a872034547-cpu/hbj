# 写章节预览目录链与段落结构补充修复

## 摘要

针对用户在网页实测中继续发现的问题，补充修复写章节实时预览和正文清洗逻辑：

1. 单小节实时生成时，如果当前章节正文文件还不存在，预览区会自动构造父级标题链：`第一章 → 第一节 → 一、`，当前叶子小节标题仍由实时生成区域单独渲染，避免出现两个重复的 `（一）` 标题。
2. 标题去重进一步兼容 `（一） 碎片化阅读时间的形成原因` 与 `（一）碎片化阅读时间的形成原因` 这类空格差异，避免连续显示两个相同小节标题。
3. 新增正文段落形态兜底：将过多短段合并为少量长段，430 字左右的小节默认合并为一个较完整段落，减少频繁换段。
4. 已重启 Streamlit 相关 Python 进程并重新启动 8503 端口服务，确保当前网页加载最新代码。

## 修改文件

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 强化 `_strip_duplicate_heading()`，忽略全角/半角空格并兼容中文括号编号。
  - 新增 `_enforce_paragraph_shape()`，将小节碎段合并为较少的长段。
  - 在生成、质量门禁、压缩后统一应用段落形态控制。

- `libriscribe/src/libriscribe/web/app.py`
  - 新增 `_section_heading_chain()`，为实时单小节预览构造章/父级目录链，但不包含当前叶子小节标题。
  - 合并小节到章节文件时同步使用更强的标题去重规则。

- `libriscribe/tests/test_commercial_routes.py`
  - 增加标题空格差异去重测试。
  - 增加段落合并测试。
  - 增加单小节预览标题链测试，并断言父级链不重复包含当前叶子标题。
