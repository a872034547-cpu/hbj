# 更新 setup.py

## 摘要
更新 `libriscribe/setup.py` 以支持二次开发架构中的新模块和依赖。

## 变更内容

### 文件: `libriscribe/setup.py`

1. **新增 install_requires 依赖**（按功能分组）:
   - RAG: `chromadb>=0.5.0`, `unstructured[all-docs]>=0.15.0`, `sentence-transformers>=3.0.0`
   - LangGraph: `langgraph>=0.2.0`, `langchain-core>=0.3.0`
   - 导出: `python-docx>=1.1.0`, `pypandoc>=1.14`
   - Web UI: `streamlit>=1.38.0`

2. **新增 console_scripts 入口点**:
   - `libriscribe-web=libriscribe.web.app:main`（Web UI 入口）
   - 保留原有 `libriscribe=libriscribe.main:app`

3. **扩展包发现**（`find_packages` include 参数）:
   - 新增: `libriscribe.rag`, `libriscribe.memory`, `libriscribe.workflow`, `libriscribe.export`, `libriscribe.web` 及其子包
   - 保留原有: `libriscribe`, `libriscribe.agents`, `libriscribe.utils`
