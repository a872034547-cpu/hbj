# 专业带格式 Word 导出脚本与网页入口

## 摘要

本次将结构化 JSON 到 Word 的独立导出脚本升级为专业排版版本，并在网页侧边栏新增“Word（带格式）导出”入口。新版导出会生成独立封面页、目录页、前言、正文、结语和参考文献，并由代码硬控制页边距、字体、字号、行距、标题样式、多级编号、页码格式、页眉页脚和参考文献悬挂缩进。

## 变更文件

- `libriscribe/scripts/export_structured_json_to_docx.py`
  - 重写为完整的专业 Word 导出脚本。
  - 新增 `export_json_data_to_docx()`，支持网页直接传入结构化数据。
  - 支持独立封面页、罗马页码目录/前言、正文阿拉伯页码、奇数页起章、页眉页脚、多级标题编号、未编号标题样式、TOC 域和参考文献样式。

- `libriscribe/src/libriscribe/web/app.py`
  - 侧边栏新增“Word（带格式）导出”按钮。
  - 新增项目书稿 Markdown 到结构化 JSON 的转换适配函数。
  - 新增 `_export_formatted_word()` 调用独立脚本生成 `_格式强控.docx`。

- `libriscribe/tests/test_export_and_quality_gate_services.py`
  - 新增独立脚本导出测试，验证正式 Word 结构、样式和页边距。

- `libriscribe/tests/test_commercial_routes.py`
  - 新增网页导出入口和结构化适配器测试。
