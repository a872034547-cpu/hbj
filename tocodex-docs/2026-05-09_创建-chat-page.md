# 2026-05-09 创建 chat.py 聊天指令页面

## 概述
创建了 Streamlit Web UI 的聊天式指令界面模块。

## 变更文件
- `libriscribe/src/libriscribe/web/pages/chat.py` — 新建

## 功能说明
- `render_chat()`: 渲染完整聊天界面，包含历史消息、输入框、侧边栏快捷按钮
- `process_command()`: 解析并执行 12 种斜杠命令（/write, /review, /edit, /outline, /concept, /characters, /worldbuilding, /cite, /export, /terminology, /help）
- `process_natural_language()`: 通过 LLM 意图识别将自然语言映射到对应命令，无法映射时直接用 LLM 回答
- 聊天历史存储在 `st.session_state.chat_messages`
- 每个命令执行时显示 spinner，结果以 markdown 渲染，错误优雅处理
