# 修复 GBK 编码错误与章节字数显示

## 日期
2026-05-09

## 问题描述
1. **GBK 编码错误**：接入自定义 AI 后，所有 AI 场景报错 `'gbk' codec can't encode character '\U0001f4dd'`。原因是 Windows 默认 GBK 编码无法处理 emoji 字符。
2. **字数不显示**：章节管理页面看不到多章节字数解析结果。

## 修复方案

### 1. GBK 编码修复（3 个文件）

**`app.py`** — 在文件顶部添加 Windows UTF-8 编码强制设置：
```python
import sys
import io
if sys.platform == "win32":
    try:
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
        sys.stderr.reconfigure(encoding="utf-8", errors="replace")
    except Exception:
        sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
        sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding="utf-8", errors="replace")
```

**`llm_client.py`** — 移除第 183 行的 `print()` 语句（只保留 `logger.exception()`）

**`prompt_integration.py`** — 将 `print(f"⚠️ ...")` 替换为 `logging.getLogger(__name__).warning(...)`

### 2. 字数显示改进

**`app.py`** 第 775 行 — 即使字数为 0 也显示提示：
```python
wc_info = f" | 📝 {wc}字" if wc > 0 else " | 📝 未设置字数"
```

## 修改文件
- `libriscribe/src/libriscribe/web/app.py` — UTF-8 编码设置 + 字数显示改进
- `libriscribe/src/libriscribe/utils/llm_client.py` — 移除 emoji print
- `libriscribe/src/libriscribe/utils/prompt_integration.py` — print → logger
