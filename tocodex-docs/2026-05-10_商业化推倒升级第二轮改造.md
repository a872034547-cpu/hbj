# 商业化推倒升级第二轮改造

## 摘要

本轮完成核心业务服务化的第二阶段落地：将持久化任务中心、资料/RAG 覆盖分析、引用证据闭环矩阵、质量中心体检视图接入现有 Streamlit 商业化路由。改造目标是让平台从“可写作工具”继续升级为“可审计、可核验、可出版交付”的商业化专著生产系统。

## 已完成内容

1. `TaskService` 从内存任务骨架升级为可选 JSON 持久化任务服务，支持任务创建、更新、恢复、按状态筛选和清理终态任务。
2. `CitationService` 增加证据绑定引用、来源文档查找、参考文献格式化和引用覆盖矩阵。
3. `SourceService` 增加来源文档覆盖分析、坏证据片段过滤、章节资料缺口矩阵。
4. `app.py` 的引用核验中心接入引用证据闭环矩阵，展示引用总数、已核验、未核验、风险引用和缺少定位指标。
5. `app.py` 的质量中心接入出版前体检、来源文档覆盖和章节资料缺口视图。
6. 新增/更新 pytest 用例覆盖持久化任务、引用证据绑定、资料覆盖统计和坏片段过滤。
