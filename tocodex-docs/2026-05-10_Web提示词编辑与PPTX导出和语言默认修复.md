# Web 提示词编辑、PPTX 导出与语言默认修复

## 摘要

本次修复围绕用户反馈的三个问题完成：

1. 文章生成质量不便排查：新增 Web 可查看、可编辑的章节写作提示词，并提供 AI 提示词分析与优化方向。
2. PPT 导出格式不对：新增 PPTX 汇报稿导出器，按封面、目录、章节摘要、章节要点、结束页组织，不再把长正文直接塞进幻灯片。
3. 项目语言重复且默认英文：统一语言选项，去掉“中文/简体中文”重复项，默认改为“简体中文”。

## 已修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 导航增加“提示词”入口。
  - 新增项目语言选项常量，默认“简体中文”。
  - 创建项目和项目设置页语言下拉统一使用去重后的语言列表。
  - 新增 PPTX 导出入口。
  - 提示词页改为可编辑当前章节写作提示词，并展示 AI 优化方向。

- `libriscribe/src/libriscribe/services/prompt_service.py`
  - 新增默认章节写作提示词模板。
  - 新增项目级提示词加载、保存、重置能力。
  - 新增提示词分析与优化方向说明。

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 章节写作时改为读取项目级 Web 可编辑提示词。
  - 自定义提示词变量错误时给出明确修正提示。

- `libriscribe/src/libriscribe/export/pptx_export.py`
  - 新增 PPTX 导出器。
  - 使用 16:9、米白/深绿配色、章节摘要和要点页组织内容。
