# 脚本导出 Word 去除章节自评结果

## 摘要

按用户要求，保留网页章节预览中的 `【自评结果】`，但在 Python 脚本导出的带格式 Word 文档中移除自评结果、评分、字数偏差等过程信息。

## 变更文件

- `libriscribe/scripts/export_structured_json_to_docx.py`

## 主要变更

- 新增导出专用清理函数 `strip_export_self_assessment()`。
- 在 `iter_paragraph_texts()` 统一段落展开入口中过滤：
  - `【自评结果】` / `【自评打分】` 块；
  - 孤立的 `字数偏差：`、`总分：`、`评分：`、`质量自检：` 等过程评分行。
- 该处理只发生在脚本导出 Word 的正文段落写入和导出字数核验路径，不修改章节生成内容，也不影响网页章节预览显示。

## 验证

已运行：

```bash
python -m py_compile scripts/export_structured_json_to_docx.py
```

并用最小样例验证 `collect_structured_body_text()` 中不再包含 `【自评结果】`、`字数偏差`、`总分`。
