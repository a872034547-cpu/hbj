# 结构化 JSON Word 导出标题编号分页与前后文献修复

## 摘要

本次修复同时处理了两类问题：

1. 结构化 JSON 脚本导出 Word 后，在部分 Word/WPS 环境中标题仍显示为“第1章 / 第1节 / 1.1”的问题。
2. 三级、四级标题如“（二）”后续内容在当前页仍有较大空白时被强制推到下一页的问题。
3. 前言/结语独立生成去除开头标题词，并按用户输入字数执行 ±8% 提示词硬约束。
4. 参考文献生成与 Word 导出清理 DOI、URL、OpenAlex、https 链接，按专著通用参考文献格式保留条目正文。

## 关键改动

- 在结构化 JSON Word 导出脚本中不再使用 Word 内置 `Heading 1/2/3/4` 作为正文标题样式，改用 `Book Chapter Heading`、`Book Section Heading`、`Book Level3 Heading`、`Book Level4 Heading`、`Book Unnumbered Heading` 自定义样式，并通过 `outlineLvl` 参与目录生成。
- 清除标题段落和标题样式上的 `w:numPr`、`w:pageBreakBefore`、`w:keepNext`、`w:keepLines`，避免 Word/WPS 自动编号和异常分页。
- 页眉的 `STYLEREF` 改为引用自定义章标题样式，避免依赖内置 Heading 1。
- 参考文献规范化时去除 `https://...`、DOI、URL、OpenAlex 等链接片段。
- 更新测试，覆盖自定义标题样式无自动编号、无分页保护、无 URL/DOI 输出，以及前言/结语/参考文献提示词与结构化导出适配器的新行为。
