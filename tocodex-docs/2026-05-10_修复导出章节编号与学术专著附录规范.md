# 修复导出章节编号混乱与学术专著附录规范

## 概要
本次修复解决导出文件中出现“第0章”、重复章标题和目录编号混乱的问题，并强化章节生成提示词与章末学术出版要素。

## 变更文件
- `libriscribe/src/libriscribe/web/app.py`
  - 导出前统一清理章节正文开头重复的一级章标题。
  - `_collect_chapters()` 同时提供 `number` 与 `chapter_number`，避免导出器默认回退为 0。
  - 导出兜底补齐参考文献、本章术语表和本章实际/目标字数偏差。
  - 从项目动态问题中提取作者/单位信息用于 DOCX、LaTeX、PDF 封面。
- `libriscribe/src/libriscribe/export/docx_export.py`
  - DOCX 导出不再默认使用第0章。
  - 统一使用“第X章 标题”格式，避免冒号格式与正文章标题重复。
  - 导出时再次清理正文中可能残留的一级章标题。
- `libriscribe/src/libriscribe/export/pdf_export.py`
  - PDF 导出强制校验有效章节编号。
  - 使用统一 display title，并清理重复章标题。
- `libriscribe/src/libriscribe/export/latex_export.py`
  - LaTeX 导出强制校验有效章节编号。
  - 使用统一显示标题写入目录，避免重复章标题。
- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 提示词加入学术专著角色设定、四级目录编号约束、禁止第0章、禁止 HTML/XML/script/iframe/代码和指令残留等规则。
  - 全章生成时自动加入章首导语、章末小结、参考文献、本章术语表和字数偏差统计。
  - 增强模型输出清洗，过滤 script、iframe 与英文指令残留。

## 验证
- 已执行 Python 编译检查：
  - `python -m py_compile src/libriscribe/web/app.py src/libriscribe/agents/chapter_writer.py src/libriscribe/export/docx_export.py src/libriscribe/export/pdf_export.py src/libriscribe/export/latex_export.py`
- 已验证重复章标题清理逻辑可将 `# 第1章 医疗诊断与AI概述` 从导出正文中移除，保留后续小节内容。
