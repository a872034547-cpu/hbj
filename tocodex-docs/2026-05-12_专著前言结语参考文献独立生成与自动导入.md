# 专著前言结语参考文献独立生成与自动导入

## 摘要

本次升级在写章节页新增“专著前后内容与参考文献”区域，支持单独编辑、保存和 AI 生成“前言”“结语”“参考文献”。生成或保存后内容会以独立 Markdown 文件存入项目目录，并在最终导出书稿中自动按顺序组装：前言在第一章前，结语在最后一章后，参考文献在结语后。

同时更新 DOCX、LaTeX、PDF、PPTX 导出逻辑，使其支持无章节编号的书稿组成部分，不再因前言/结语/参考文献没有 chapter_number 而报错。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 新增 `MANUSCRIPT_PARTS` 配置。
  - 新增前言/结语/参考文献读写、生成提示词和 AI 生成函数。
  - 在写章节页新增独立生成与编辑入口。
  - 更新 `_collect_chapters()`，导出时自动按“前言 → 正文章节 → 结语 → 参考文献”排序。

- `libriscribe/src/libriscribe/export/docx_export.py`
  - 支持无编号书稿组成部分。
  - 自动去除前言/结语/参考文献正文中重复的一级标题。

- `libriscribe/src/libriscribe/export/latex_export.py`
  - 支持无编号书稿组成部分。
  - 导出时用显示标题生成 `chapter*` 并加入目录。

- `libriscribe/src/libriscribe/export/pdf_export.py`
  - ReportLab 和 FPDF 两条路径均支持无编号书稿组成部分。

- `libriscribe/src/libriscribe/export/pptx_export.py`
  - 汇报稿标题提取优先使用 `display_title`，兼容“前言/结语/参考文献”。

- `libriscribe/tests/test_commercial_routes.py`
  - 新增测试覆盖书稿组成部分排序、导出器无编号部分兼容、写章节页入口文案。
