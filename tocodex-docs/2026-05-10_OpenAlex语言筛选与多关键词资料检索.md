# OpenAlex语言筛选与多关键词资料检索

## 摘要

本次更新围绕资料页的专著写作检索体验进行了修复和增强：清理旧项目中的 `No description provided.` 占位文本，增加可编辑的多关键词检索框，并为 OpenAlex 检索增加中文、英文、全部文献范围筛选。同时取消默认按被引量排序，改用 OpenAlex 相关性排序，以减少高被引但不符合大纲的无关结果。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 资料页自动清理 `No description provided.`。
  - 新增“项目描述与资料检索词整理”区域，支持手动编辑项目描述和 AI 根据书名、大纲、检索词自动整理专著定位。
  - 将资料联网检索词改为可编辑多行文本框，每行作为一个独立关键词检索入口。
  - OpenAlex 单次检索和大纲批量检索均增加中文/英文/全部文献筛选。

- `libriscribe/src/libriscribe/services/literature_search_service.py`
  - 增加 `language_filter` 参数。
  - 支持 OpenAlex `language:zh`、`language:en` 过滤。
  - 默认不再添加 `sort=cited_by_count:desc`，改用相关性排序。
  - 大纲检索透传语言筛选参数。

- `libriscribe/src/libriscribe/knowledge_base.py`
  - 新项目默认值调整为专著写作模式。
  - 增加旧占位文本清理校验，加载旧项目时自动过滤 `No description provided.` 等遗留占位值。

- `libriscribe/src/libriscribe/web/components/progress_bar.py`
  - 将旧小说流程进度项调整为专著写作流程项。

- `libriscribe/tests/test_outline_pipeline_services.py`
  - 更新 OpenAlex 相关测试，覆盖语言筛选、相关性排序和大纲检索参数透传。
