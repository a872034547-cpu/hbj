# 生成链路中文大纲层级统一修复

## 摘要

本次修复把章节大纲的用户可见层级统一为中文格式，避免内部实现编号 `1.1`、`1.1.1`、`1.1.1.1` 泄露到大纲页、写章节页、生成进度、生成正文 Markdown 标题和小节合并逻辑中。

统一规则：

- `1.1` 显示为 `第一节 ...`
- `1.1.1` 显示为 `一、 ...`
- `1.1.1.1` 显示为 `（一） ...`

内部 dotted 编号仍保留作为排序、匹配、文件名和数据 ID，不再作为用户可见标题输出。

## 修改文件

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 新增统一中文层级格式化入口。
  - 章节生成的 prompt 大纲树、进度标题、正文 Markdown 标题统一使用中文层级。
  - 小节标题匹配兼容旧数字标题和新中文标题。

- `libriscribe/src/libriscribe/web/app.py`
  - 大纲管理页“子节列表”改为中文层级显示。
  - 写章节页和实时生成标题继续使用同一中文格式化入口。
  - 小节合并时使用原始小节标题进行匹配，避免把展示标题误传给合并逻辑。
  - 后台生成完成提示改为中文层级，不再返回 `1.1.1.1 小节已生成完成`。

- `libriscribe/tests/test_commercial_routes.py`
  - 增加大纲页、后台返回、实时合并不泄露数字标题的回归测试。
  - 增加章节生成链路测试，覆盖 prompt 大纲树、生成进度、生成 Markdown 标题均为中文层级。
