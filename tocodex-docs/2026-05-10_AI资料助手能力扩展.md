# AI 资料助手能力扩展

## 摘要

回应“AI 资料助手是否只能生成检索结果”的问题，已将资料助手从三项单一输出扩展为更清晰的多任务助手。现在它不仅能生成检索词，也能整理检索结果、基于已上传证据片段写作、分析资料缺口、生成文献核查计划。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 将“AI 资料助手：生成检索词 / 整理结果 / 基于资料写作”改为“AI 资料助手：检索词 / 结果整理 / 资料内写作 / 缺口分析”。
  - 新增任务类型：
    - `分析资料缺口`
    - `生成文献核查计划`
  - 为每个任务提供不同默认提示词。
  - 将 OpenAlex 候选、搜索 API 大纲网页结果、搜索 API 参考文献核查结果、已上传证据片段一起纳入 AI 上下文。
  - 增加上下文指标展示：已上传证据片段、OpenAlex候选、大纲网页检索组、参考文献网页核查组。
  - 强化约束：网页线索不能直接标为真实引用，资料内写作必须引用已有证据片段。
