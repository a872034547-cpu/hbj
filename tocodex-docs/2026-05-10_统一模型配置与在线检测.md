# 统一模型配置与在线检测

## 摘要

本次更新将官方模型与自定义 OpenAI 兼容平台统一到「模型配置」页面维护。项目创建和项目管理不再重复填写供应商、API Base、API Key、模型名，而是直接选择已配置并启用的模型档案。

## 主要变化

- 新增统一模型档案配置文件：`libriscribe/config/model_profiles.json`。
- 「模型配置」页面支持官方平台与自定义平台统一编辑、保存、删除。
- 「模型配置」页面支持检测当前模型，以及一键检测全部已启用模型在线状态。
- 项目创建表单改为只选择可用模型档案。
- 项目设置/项目管理改为只选择同一套模型档案。
- 项目数据新增 `model_profile_id`，保留旧字段用于兼容已有项目和后台任务。
- LLM 客户端支持官方平台也使用模型档案中的显式 API Key、API Base 和模型名。
