# UI 舒适版全局优化

## 摘要

根据反馈，已进一步将界面改为更舒适、克制、适合长时间写作的样式。重点处理了左侧导航上方白色残留、字体观感异常和图标/emoji 渲染异常问题。

## 主要变化

- 页面整体从“科技/AI 风格”进一步收敛为低饱和米白学术写作界面。
- 强制覆盖 Streamlit 顶部 header、toolbar、decoration、sidebar header、collapsed control 等容易出现白底的区域。
- 侧边栏所有嵌套容器统一使用米白侧栏背景，进一步修复左侧工作区顶部白色残留。
- 字体统一改为系统中文 UI 字体栈：`Microsoft YaHei UI`、`Microsoft YaHei`、`PingFang SC`、`Segoe UI`、`Arial`，避免远程字体加载和中英混排异常。
- 移除页面中可见 emoji 图标，改为文字表达，避免 Windows/浏览器 emoji 渲染导致图标发虚、错位、缺字。
- 降低背景网格对比度，卡片、按钮、输入框、标签页、聊天消息都改为更清晰、更耐看的低饱和样式。
- 保持业务逻辑不变，仅修改全局样式和少量显示文案。
