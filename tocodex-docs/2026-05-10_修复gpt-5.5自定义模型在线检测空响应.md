# 修复 gpt-5.5 自定义模型在线检测空响应

## 摘要

本次修复优先处理 `gpt-5.5 · 自定义 OpenAI 兼容平台` 在应用内检测失败、提示“模型返回空响应”的问题。

实际排查发现：模型配置已正确读取，OpenAI Python SDK 调用被目标中转服务拦截并返回 `Your request was blocked.`；改用 `requests` 直连 `/chat/completions` 并设置兼容请求头后，在线检测已成功返回模型正文。

## 变更文件

- `libriscribe/src/libriscribe/utils/llm_client.py`
  - 增加 OpenAI-compatible 响应安全序列化与响应预览。
  - 增强正文提取能力，兼容 `choices[].text`、`output_text`、`output`、嵌套 `content` 分块等结构。
  - 保留 OpenAI SDK 调用，同时增加 `requests.post` 原始 HTTP 兜底调用，绕过部分中转站对 SDK 默认请求头的拦截。
  - 增加 `responses.create()` 兜底路径。

- `libriscribe/src/libriscribe/web/app.py`
  - 优化模型在线检测错误信息：不再简单提示检查密钥/模型/API Base，而是展示真实诊断信息或响应预览。
  - 检测提示词改为更稳定的短提示，并降低温度。

## 验证结果

- `python -m py_compile src\libriscribe\utils\llm_client.py src\libriscribe\web\app.py` 通过。
- 本地加载 `gpt-5.5` 配置成功，API 密钥未在输出中明文打印。
- 在线检测结果：成功。
- 返回预览：`Hi! How can I help?`
