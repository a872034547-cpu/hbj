# LibriScribe 新服务器 Linux 小白安装文档

> 适合第一次在 Linux 服务器上部署本项目的用户。按本文档从上到下执行，即可在新服务器上启动网页写书系统。
>
> 推荐系统：Ubuntu 22.04 LTS / Ubuntu 24.04 LTS / Debian 12。
>
> 推荐服务器配置：2 核 CPU、4GB 内存、40GB 硬盘起步；如果要做资料向量索引、PDF/Word 解析、长文生成，建议 4 核 CPU、8GB 内存、80GB 硬盘以上。
>
> 本文示例项目目录：`/opt/libriscribe`。
>
> 本文默认使用普通用户 `root` 或具备 `sudo` 权限的用户执行命令。如果你看到命令前面有 `sudo`，直接复制执行即可。

---

## 0. 安装完成后你会得到什么

完成后，你可以在浏览器访问：

```text
http://服务器公网IP:8501
```

进入网页端写书系统，完成：

1. 创建写书项目。
2. 配置 AI 模型。
3. 上传资料。
4. 生成大纲。
5. 生成章节正文。
6. 生成前言、结语、参考文献。
7. 导出 Word、Word（带格式）、PDF、PPTX 等文件。

## 1. 新服务器准备

### 1.1 登录服务器

如果你使用云服务器，通常云厂商会给你：

```text
服务器公网 IP
用户名，例如 root、ubuntu、admin
密码，或 SSH 密钥
```

在你自己的电脑上打开终端：

- Windows：可以用 PowerShell、Windows Terminal、MobaXterm、FinalShell、Xshell。
- macOS：打开“终端”。
- Linux：打开 Terminal。

用 SSH 登录服务器：

```bash
ssh root@你的服务器公网IP
```

例如：

```bash
ssh root@123.123.123.123
```

如果服务器用户名不是 `root`，例如是 `ubuntu`：

```bash
ssh ubuntu@123.123.123.123
```

第一次连接可能提示：

```text
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

输入：

```text
yes
```

然后按回车。

---

### 1.2 确认当前系统版本

登录服务器后，执行：

```bash
cat /etc/os-release
```

如果看到类似：

```text
Ubuntu 22.04
Ubuntu 24.04
Debian GNU/Linux 12
```

说明适合按本文档继续安装。

---

### 1.3 更新系统软件源

Ubuntu / Debian 执行：

```bash
sudo apt update
```

再执行系统基础升级：

```bash
sudo apt upgrade -y
```

这一步可能需要几分钟。

如果过程中提示是否继续，输入：

```text
Y
```

然后按回车。

## 2. 安装系统基础依赖

项目需要 Python、Git、编译工具、文档解析工具等。

### 2.1 一次性安装常用依赖

执行：

```bash
sudo apt install -y \
  python3 \
  python3-pip \
  python3-venv \
  python3-dev \
  git \
  curl \
  wget \
  build-essential \
  pkg-config \
  libmagic1 \
  poppler-utils \
  tesseract-ocr \
  tesseract-ocr-chi-sim \
  pandoc \
  fonts-noto-cjk \
  unzip
```

这些依赖的作用：

| 依赖 | 作用 |
|---|---|
| `python3` | 运行 Python 项目 |
| `python3-pip` | 安装 Python 依赖包 |
| `python3-venv` | 创建 Python 虚拟环境 |
| `git` | 下载和更新项目代码 |
| `build-essential` | 编译部分 Python 依赖 |
| `libmagic1` | 文件类型识别，资料解析会用到 |
| `poppler-utils` | PDF 解析相关工具 |
| `tesseract-ocr` | OCR 识别工具 |
| `tesseract-ocr-chi-sim` | 简体中文 OCR 识别包 |
| `pandoc` | 文档格式转换 |
| `fonts-noto-cjk` | 中文字体，避免 PDF/文档中文乱码 |

## 4. 下载项目代码

### 4.1 从 GitHub 下载

如果你的服务器可以访问 GitHub，执行：

```bash
git clone https://github.com/guerra2fernando/libriscribe.git .
```

注意：命令最后有一个英文句号 `.`，意思是把项目下载到当前目录 `/opt/libriscribe`。

### 4.2 如果 GitHub 下载很慢或失败

可以先在本地电脑下载压缩包，再上传到服务器。

#### 方法 A：用 `scp` 上传

在本地电脑执行：

```bash
scp libriscribe.zip root@你的服务器公网IP:/opt/libriscribe/
```

登录服务器后解压：

```bash
cd /opt/libriscribe
unzip libriscribe.zip
```

如果解压后里面多了一层目录，例如 `/opt/libriscribe/libriscribe-main`，进入该目录：

```bash
cd /opt/libriscribe/libriscribe-main
```

#### 方法 B：用宝塔 / 1Panel / 云厂商文件管理器上传

1. 在网页面板中进入 `/opt/libriscribe`。
2. 上传项目压缩包。
3. 解压。
4. 确保能看到 `requirements.txt`、`setup.py`、`src` 等文件。

---

### 4.3 检查项目目录是否正确

执行：

```bash
pwd
```

应该看到类似：

```text
/opt/libriscribe
```

或：

```text
/opt/libriscribe/libriscribe-main
```

再执行：

```bash
ls
```

应该能看到：

```text
README.md
requirements.txt
setup.py
src
scripts
config
```

如果看不到这些文件，说明当前目录不对，需要 `cd` 进入真正的项目根目录。

## 5. 创建 Python 虚拟环境

虚拟环境用于隔离依赖，避免污染服务器系统环境。

### 5.1 进入项目根目录

如果你的项目在 `/opt/libriscribe`：

```bash
cd /opt/libriscribe
```

如果你的项目在 `/opt/libriscribe/libriscribe-main`：

```bash
cd /opt/libriscribe/libriscribe-main
```

后文统一称为“项目根目录”。

---

### 5.2 创建虚拟环境

```bash
python3 -m venv .venv
```

执行后，项目根目录会出现 `.venv` 文件夹。

---

### 5.3 激活虚拟环境

```bash
source .venv/bin/activate
```

激活成功后，命令行前面通常会出现：

```text
(.venv)
```

例如：

```text
(.venv) root@server:/opt/libriscribe#
```

只要看到 `(.venv)`，说明虚拟环境已经启用。

---

### 5.4 升级 pip、setuptools、wheel

```bash
python -m pip install --upgrade pip setuptools wheel
```

如果服务器访问 PyPI 很慢，可以使用清华源：

```bash
python -m pip install --upgrade pip setuptools wheel -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 6. 安装项目依赖

### 6.1 推荐安装方式

确保已经激活虚拟环境，并且命令行前面有 `(.venv)`。

执行：

```bash
python -m pip install -r requirements.txt
```

这一步可能需要 5-20 分钟，取决于服务器网络和性能。

如果网络慢，使用清华源：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 6.2 安装当前项目为可编辑模式

```bash
python -m pip install -e .
```

如果网络慢：

```bash
python -m pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 6.3 如果安装 `unstructured[all-docs]` 很慢或失败

`unstructured[all-docs]` 用于 PDF、Word、Excel 等复杂资料解析，依赖较多，安装慢是正常的。

先单独重试：

```bash
python -m pip install "unstructured[all-docs]>=0.15.0" -i https://pypi.tuna.tsinghua.edu.cn/simple
```

再安装完整依赖：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果你只是先启动网页体验，不急着解析复杂 PDF/Word，可以临时安装核心依赖：

```bash
python -m pip install typer openai python-dotenv pydantic pydantic-settings beautifulsoup4 requests markdown fpdf anthropic google-generativeai tenacity rich pick tavily-python chromadb sentence-transformers langgraph langchain-core python-docx pypandoc reportlab python-pptx streamlit pytest -i https://pypi.tuna.tsinghua.edu.cn/simple
```

然后再执行：

```bash
python -m pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 7. 配置环境变量和 AI 模型

系统需要 AI 模型才能生成大纲和正文。

支持：

- OpenAI
- DeepSeek
- Claude
- Gemini
- Mistral
- OpenAI-compatible 自定义接口
- 资料索引 / 联网检索 API，例如 Tavily

推荐小白优先使用网页里的“模型设置”配置；如果你需要服务器重启后也保留默认配置，可以同时配置 `.env` 文件。

---

### 7.1 复制 `.env.example`

在项目根目录执行：

```bash
cp .env.example .env
```

如果 `.env.example` 不存在，可以直接新建：

```bash
touch .env
```

---

### 7.2 编辑 `.env`

如果服务器安装了 `nano`，执行：

```bash
nano .env
```

如果没有 `nano`：

```bash
sudo apt install -y nano
nano .env
```

填入你使用的 API Key，例如：

```env
OPENAI_API_KEY=你的OpenAI密钥
DEEPSEEK_API_KEY=你的DeepSeek密钥
CLAUDE_API_KEY=你的Claude密钥
GOOGLE_AI_STUDIO_API_KEY=你的Gemini密钥
MISTRAL_API_KEY=你的Mistral密钥
TAVILY_API_KEY=你的Tavily密钥

EMBEDDING_PROVIDER=openai
EMBEDDING_MODEL=text-embedding-3-small
CHROMA_PERSIST_DIR=./chroma_db

STREAMLIT_SERVER_PORT=8501
STREAMLIT_SERVER_ADDRESS=0.0.0.0

MAX_REVIEW_ITERATIONS=3
CRITIC_SCORE_THRESHOLD=8.0

PANDOC_PATH=/usr/bin/pandoc
REFERENCE_FORMAT=gbt7714
```

`nano` 保存方法：

1. 按 `Ctrl + O`。
2. 按回车确认保存。
3. 按 `Ctrl + X` 退出。

---

### 7.3 API Key 安全提醒

不要把 `.env` 文件发给别人。

不要在截图里泄露：

```text
API Key
API Base
模型平台账号
```

如果 API Key 泄露，应立即到模型平台后台删除或重置。

## 9. 如果浏览器打不开怎么办

### 9.1 先确认服务是否还在运行

如果你当前终端还显示 Streamlit 日志，说明服务正在运行。

如果终端已经退出，重新启动：

```bash
cd /opt/libriscribe
source .venv/bin/activate
python -m streamlit run src/libriscribe/web/app.py --server.address 0.0.0.0 --server.port 8501
```

---

### 9.2 检查服务器本机端口

重新开一个 SSH 窗口，执行：

```bash
ss -lntp | grep 8501
```

如果看到类似：

```text
LISTEN 0 128 0.0.0.0:8501
```

说明服务已经监听 8501 端口。

如果没有任何输出，说明服务没启动成功，需要回到启动终端查看报错。

---

### 9.3 放行服务器防火墙 `ufw`

如果服务器启用了 `ufw` 防火墙，执行：

```bash
sudo ufw status
```

如果状态是 `active`，放行 8501：

```bash
sudo ufw allow 8501/tcp
```

再次查看：

```bash
sudo ufw status
```

---

### 9.4 云服务器安全组放行 8501

很多云服务器除了 Linux 防火墙，还有“安全组”。

请到云厂商控制台放行入站端口：

```text
协议：TCP
端口：8501
来源：0.0.0.0/0
```

常见云厂商入口：

| 云厂商 | 需要找的功能 |
|---|---|
| 阿里云 | ECS 安全组 / 入方向规则 |
| 腾讯云 | 云服务器 CVM / 安全组 / 入站规则 |
| 华为云 | 弹性云服务器 / 安全组 |
| AWS | EC2 Security Groups / Inbound rules |
| Azure | Network security group / Inbound port rules |

放行后，再访问：

```text
http://服务器公网IP:8501
```

---

### 9.5 如果 8501 被占用

换成 8502 启动：

```bash
python -m streamlit run src/libriscribe/web/app.py --server.address 0.0.0.0 --server.port 8502
```

同时放行防火墙和安全组的 8502 端口。

浏览器访问：

```text
http://服务器公网IP:8502
```

## 10. 设置后台长期运行

手动启动的缺点：SSH 断开后，服务可能停止。推荐用 `systemd` 设置为系统服务。

---

### 10.1 确认项目真实路径

执行：

```bash
pwd
```

假设输出是：

```text
/opt/libriscribe
```

后文以 `/opt/libriscribe` 为例。如果你的路径不是这个，请把命令里的路径改成你的真实路径。

---

### 10.2 创建 systemd 服务文件

执行：

```bash
sudo nano /etc/systemd/system/libriscribe.service
```

粘贴以下内容：

```ini
[Unit]
Description=LibriScribe Streamlit Web App
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/libriscribe
Environment="PATH=/opt/libriscribe/.venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
ExecStart=/opt/libriscribe/.venv/bin/python -m streamlit run src/libriscribe/web/app.py --server.address 0.0.0.0 --server.port 8501 --server.headless true
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

如果你的项目不是 `/opt/libriscribe`，必须修改三处：

```text
WorkingDirectory=/你的项目路径
Environment="PATH=/你的项目路径/.venv/bin:..."
ExecStart=/你的项目路径/.venv/bin/python ...
```

保存并退出：

1. 按 `Ctrl + O`。
2. 按回车。
3. 按 `Ctrl + X`。

---

### 10.3 启用并启动服务

重新加载 systemd：

```bash
sudo systemctl daemon-reload
```

设置开机自启：

```bash
sudo systemctl enable libriscribe
```

启动服务：

```bash
sudo systemctl start libriscribe
```

查看状态：

```bash
sudo systemctl status libriscribe
```

如果看到：

```text
active (running)
```

说明服务已经在后台运行。

按 `q` 退出状态页面。

---

### 10.4 查看服务日志

如果网页打不开或报错，查看日志：

```bash
sudo journalctl -u libriscribe -f
```

退出日志查看：

```text
Ctrl + C
```

---

### 10.5 常用 systemd 命令

```bash
# 启动
sudo systemctl start libriscribe

# 停止
sudo systemctl stop libriscribe

# 重启
sudo systemctl restart libriscribe

# 查看状态
sudo systemctl status libriscribe

# 查看实时日志
sudo journalctl -u libriscribe -f

# 取消开机自启
sudo systemctl disable libriscribe
```

## 11. 可选：用 Nginx 配置域名访问

如果你有域名，例如：

```text
write.example.com
```

可以用 Nginx 反向代理，让用户访问：

```text
http://write.example.com
```

而不是：

```text
http://服务器公网IP:8501
```

---

### 11.1 安装 Nginx

```bash
sudo apt install -y nginx
```

启动 Nginx：

```bash
sudo systemctl enable nginx
sudo systemctl start nginx
```

---

### 11.2 新建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/libriscribe
```

粘贴：

```nginx
server {
    listen 80;
    server_name write.example.com;

    client_max_body_size 200m;

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600;
    }
}
```

把 `write.example.com` 改成你的真实域名。

保存退出。

---

### 11.3 启用站点

```bash
sudo ln -s /etc/nginx/sites-available/libriscribe /etc/nginx/sites-enabled/libriscribe
```

测试配置：

```bash
sudo nginx -t
```

如果看到：

```text
syntax is ok
test is successful
```

重启 Nginx：

```bash
sudo systemctl restart nginx
```

---

### 11.4 域名解析

到你的域名服务商后台添加解析：

```text
类型：A
主机记录：write
记录值：服务器公网IP
```

等待解析生效后，浏览器打开：

```text
http://write.example.com
```

---

### 11.5 可选：配置 HTTPS

安装 Certbot：

```bash
sudo apt install -y certbot python3-certbot-nginx
```

申请证书：

```bash
sudo certbot --nginx -d write.example.com
```

按提示填写邮箱并同意协议。

完成后访问：

```text
https://write.example.com
```

## 12. 第一次使用：完整写书流程

### 12.1 打开网页

浏览器访问：

```text
http://服务器公网IP:8501
```

如果配置了域名，则访问：

```text
https://你的域名
```

---

### 12.2 配置模型

进入左侧：

```text
模型设置
```

填写：

```text
模型供应商
API Base
API Key
模型名称
```

常见自定义 OpenAI-compatible 配置示例：

```text
模型供应商：custom
API Base：https://你的接口地址/v1
API Key：你的密钥
模型名称：你的模型名
```

注意：

1. `API Base` 通常以 `/v1` 结尾。
2. `API Key` 不要有中文、空格、换行。
3. 模型名称必须和接口支持的模型名一致。
4. 保存后先测试连接。

---

### 12.3 创建项目

进入左侧：

```text
① 项目
```

填写：

```text
项目名称：例如 我的第一本专著
书名：例如 人工智能赋能高职图书馆阅读推广研究
类型：专著
目标读者：高校教师、图书馆工作人员、研究人员
描述：说明这本书要解决什么问题
```

点击创建项目。

项目通常会保存在：

```text
/opt/libriscribe/projects/你的项目名
```

## 16. 常见问题和解决办法

### 16.1 `python3: command not found`

说明没安装 Python。

执行：

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

---

### 16.2 `pip install` 很慢

使用国内源：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

也可以临时提高超时时间：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 120
```

---

### 16.3 `ModuleNotFoundError: No module named 'xxx'`

一般是虚拟环境没激活，或依赖没安装完整。

执行：

```bash
cd /opt/libriscribe
source .venv/bin/activate
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

然后重启：

```bash
sudo systemctl restart libriscribe
```

---

### 16.4 `streamlit: command not found`

不要直接运行 `streamlit`，使用：

```bash
python -m streamlit run src/libriscribe/web/app.py --server.address 0.0.0.0 --server.port 8501
```

如果仍失败，安装 Streamlit：

```bash
python -m pip install streamlit -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 16.5 网页打不开 `服务器IP:8501`

按顺序检查：

1. 服务是否运行：

```bash
sudo systemctl status libriscribe
```

2. 端口是否监听：

```bash
ss -lntp | grep 8501
```

3. Linux 防火墙是否放行：

```bash
sudo ufw allow 8501/tcp
```

4. 云服务器安全组是否放行 8501。

5. 启动命令是否使用了：

```text
--server.address 0.0.0.0
```

如果只监听 `localhost` 或 `127.0.0.1`，外部浏览器无法访问。

---

### 16.6 上传大文件失败

如果使用 Nginx，需要在 Nginx 配置中增加：

```nginx
client_max_body_size 200m;
```

修改后测试并重启：

```bash
sudo nginx -t
sudo systemctl restart nginx
```

---

### 16.7 AI 生成失败或生成空内容

常见原因：

1. API Key 填错。
2. API Base 填错。
3. 模型名填错。
4. 账户余额不足。
5. 当前模型没有权限。
6. API Key 里复制进了空格、换行或中文字符。
7. 服务器网络访问不了模型 API。

处理步骤：

1. 进入网页左侧“模型设置”。
2. 检查 `API Base`、`API Key`、模型名。
3. 删除 API Key 前后的空格。
4. 保存后重新测试连接。
5. 查看服务日志：

```bash
sudo journalctl -u libriscribe -f
```

如果日志提示 `insufficient_user_quota`，说明账户额度不足，需要充值或换模型。

---

### 16.8 PDF 或 Word 资料解析失败

先确认系统依赖已安装：

```bash
sudo apt install -y libmagic1 poppler-utils tesseract-ocr tesseract-ocr-chi-sim pandoc
```

再确认 Python 依赖：

```bash
cd /opt/libriscribe
source .venv/bin/activate
python -m pip install "unstructured[all-docs]>=0.15.0" -i https://pypi.tuna.tsinghua.edu.cn/simple
```

重启服务：

```bash
sudo systemctl restart libriscribe
```

---

### 16.9 中文乱码或 PDF 中文显示异常

安装中文字体：

```bash
sudo apt install -y fonts-noto-cjk
```

刷新字体缓存：

```bash
fc-cache -fv
```

重启服务：

```bash
sudo systemctl restart libriscribe
```

---

### 16.10 内存不足、安装依赖被杀死

如果服务器只有 1GB 或 2GB 内存，安装 `unstructured`、`sentence-transformers` 可能失败。

可以临时创建 2GB swap：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
free -h
```

再重新安装依赖。

如果想开机自动启用 swap：

```bash
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## 19. 服务器安全建议

### 19.1 不建议长期直接暴露 8501 端口

如果只是个人临时使用，可以直接开放 `8501`。

如果多人长期使用，建议：

1. 使用 Nginx + 域名。
2. 配置 HTTPS。
3. 限制安全组来源 IP。
4. 不要公开 `.env`、备份文件、项目目录。

---

### 19.2 限制安全组来源 IP

如果只有你自己使用，可以把安全组来源从：

```text
0.0.0.0/0
```

改成你自己的公网 IP：

```text
你的公网IP/32
```

这样别人无法访问你的服务。

---

### 19.3 定期备份

建议至少每周备份一次：

```bash
cd /opt/libriscribe
mkdir -p backups
tar -czf backups/libriscribe-backup-$(date +%F-%H%M%S).tar.gz projects config chroma_db .env
```

## 20. 小白注意事项

1. 每次手动运行项目，都要先执行 `source .venv/bin/activate`。
2. 如果使用 systemd 后台运行，平时只需要 `sudo systemctl restart libriscribe`。
3. 服务器浏览器打不开时，优先检查安全组和防火墙。
4. AI 生成失败时，优先检查 API Key、API Base、模型名、余额。
5. 上传资料失败时，优先检查依赖、文件大小、Nginx 上传限制。
6. 导出 Word 后，目录页码需要在 Word/WPS 中手动“更新域”。
7. 不要把 `.env`、API Key、备份包发给别人。
8. 生成内容必须人工审校，不建议直接作为最终出版稿。
9. 生产环境建议使用域名 + HTTPS，不建议长期裸露 `8501` 端口。
10. 项目目录、备份目录、导出目录要定期清理，避免磁盘占满。
