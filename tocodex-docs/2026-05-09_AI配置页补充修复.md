# AI 配置页补充修复

## 修复内容

### 1. 修复 `project is not defined`
原因：在重构 AI 测试函数时，把“保存配置”和“配置摘要”区块错误放进了 [`_do_test_connection`](libriscribe/src/libriscribe/web/app.py:1511) 作用域内，导致函数内访问不到 [`project`](libriscribe/src/libriscribe/web/app.py:1435)。

修复：将以下区块移回 [`render_ai_config_page`](libriscribe/src/libriscribe/web/app.py:1430) 内部：
- 保存配置区块
- 当前配置摘要区块

### 2. 修正自定义平台报错提示
根据终端日志：
- `openai.PermissionDeniedError: Your request was blocked.`

这说明：
- 请求已经成功到达目标平台
- 不是“连不上”
- 是对方平台拒绝/拦截了当前请求

因此前端错误提示已改为更准确的说明：
- 账号权限不足
- API Key 没有该模型权限
- 服务端风控/白名单限制
- 平台策略拦截

### 3. 保存时标准化 API Base
保存自定义 AI 配置时会对 base URL 做 `rstrip('/')`，避免重复斜杠。

## 涉及文件
- `libriscribe/src/libriscribe/web/app.py`

## 结论
当前自定义平台真实状态不是本地代码无法连接，而是目标服务返回 `Your request was blocked.`。这属于对方平台权限/策略问题，不是前端连接代码故障。
