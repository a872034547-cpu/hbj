# 升级强制规范版提示词与反幻觉、反虚假操作、50分制自检

## 概要
按用户提供的完整"学术专著生成系统提示词（强制规范版）"全面升级 `academic_prompt.py` 中的 `ACADEMIC_MONOGRAPH_SYSTEM_PROMPT` 及自检机制，并将反幻觉/反虚假操作条款同步到所有文章生成入口。

## 主要变更

### 1. `academic_prompt.py` — 核心提示词与自检引擎
- `ACADEMIC_MONOGRAPH_SYSTEM_PROMPT` 替换为强制规范版：
  - 绝对禁止幻觉、虚假操作、省略占位符、非正文内容
  - 强制国标引用：GB/T 7713.2-2022、GB/T 7714-2015、CY/T 122-2015/121-2015、GB/T 15835-2011
  - 信息缺失声明："【信息缺失】需要您提供……"
  - 评分自检从6项60分改为5项50分
- `self_assess_chapter()` 更新为5维度50分制
- `build_self_assessment_table()` 更新为5维度格式
- 通过阈值从 48/60 改为 40/50

### 2. `chapter_writer.yml` — 外部提示词模板
- 版本升级为 4.0，内容同步替换为强制规范版

### 3. `chapter_writer.py` — 主写作 Agent
- 自检阈值从 48 改为 40（80% of 50）
- 场景提示增加反幻觉/反虚假操作条款

### 4. `workflow/nodes.py` — LangGraph 节点
- writer/editor 提示增加反幻觉/反虚假操作条款
- editor_node 增加 finalize_academic_chapter() 调用

### 5. `editor.py`、`style_editor.py`、`formatting.py`
- 提示增加50分制说明和反幻觉/反虚假操作条款

### 6. `prompt_integration.py`
- 自动注入 ACADEMIC_MONOGRAPH_SYSTEM_PROMPT 的 Agent 名称列表
