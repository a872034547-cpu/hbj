# 商业化推倒升级第三轮改造

## 摘要

本轮完成全流程测试体系与上线门禁基础设施落地。目标是将“研发完成后人工凭经验检查”升级为可重复执行、可生成报告、可阻断上线的质量门禁流程，覆盖编译、单元/集成测试、商业化路由冒烟检查与验收报告产物。

## 已完成内容

1. 新增统一上线门禁脚本 `scripts/quality_gate.py`。
2. 门禁脚本固定执行：
   - `python -m compileall src`
   - `python -m pytest -q`
   - 商业化路由冒烟检查
3. 门禁脚本自动生成 `reports/release_gate_report.md`，记录每一步命令、通过/失败状态、耗时、stdout、stderr 和整体状态。
4. 新增商业化路由测试，确保前端导航 `NAV_PAGES` 与后端页面渲染器 `PAGE_RENDERERS` 同步。
5. 新增 Playbook 测试，确保学术专著、教材、行业白皮书、政策研究四类商业化生产剧本存在。
6. 新增导出门面测试，验证 `ExportService` 会正确委托 DOCX/PDF/LaTeX exporter。
7. 新增核心服务集成测试，覆盖资料 → 证据 → 引用 → 质量 → 流水线链路。
