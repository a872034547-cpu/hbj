# 移除文献核查闭环与引用管理优化

## 变更摘要

- 资料页移除了“AI 文献核查闭环：按大纲检索 / 二次审核真实性 / 加入资料库”板块，避免依赖未安装的 Tavily 工作流。
- OpenAlex 生成并导入的引用改为直接进入已核验引用记录，不再要求二次核验。
- 引用页面新增“引用记录管理”，支持查看引用详情与删除引用，同时保留自定义添加引用入口。
- 用户说明书补充了 OpenAlex 免核验导入、引用查看/删除，以及 Tavily 板块移除说明。
