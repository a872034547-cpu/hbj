# OpenAlex 真实检索与图文优化入口

## 摘要

本次改造补齐了“一小时写书”流程中的可选图文同步生成入口，并将资料页的 OpenAlex 文献能力从占位预留升级为真实检索、中文期刊引用格式化和引用候选导入。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 在正文编辑页新增“图文优化”按钮与“图文同步生成（可选）”面板。
  - 在资料页新增 OpenAlex 学术文献自动检索与引用生成区，支持 API Key 会话输入、关键词检索、近 10 年筛选、生成纯文本参考文献与导入引用中心。
- `libriscribe/src/libriscribe/services/literature_search_service.py`
  - 实现 OpenAlex Works API 真实请求。
  - 支持 `OPENALEX_API_KEY` 环境变量与调用参数传入 API Key。
  - 增加 OpenAlex work 规范化、中文期刊引用格式化、格式化引用导入、资料文献导入。
  - 提供 `fetch_and_format_citations(keywords, num_results=5)` 兼容用户要求的调用形式。
- `libriscribe/tests/test_outline_pipeline_services.py`
  - 更新测试，避免单元测试依赖外部网络。
  - 增加 OpenAlex URL 构造、密钥隐藏、引用格式化与导入行为断言。
