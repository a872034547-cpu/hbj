# 完整AI专著固定提示词接入完成

## 摘要

已将用户提供的完整 AI 学术专著固定提示词集中沉淀为共享模块，并接入核心文章/章节生成、工作流写作润色、传统编辑、风格润色、整书格式化以及外部 Prompt 模板集成路径。生成/润色后的章节会统一执行学术专著后处理：正文首行缩进规范化、自评打分追加，以及低于 80% 时的系统级格式化重写兜底。

同时补齐了工作流编辑节点之前遗漏的 `finalize_academic_chapter` 处理，并通过 `py_compile` 验证相关 Python 文件语法通过。

## 变更文件

- `libriscribe/src/libriscribe/utils/academic_prompt.py`
  - 新增固定学术专著总提示词。
  - 新增字数统计、首行缩进规范化、自评打分、章节最终化工具函数。

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 章节/小节生成统一注入固定专著提示词。
  - 完整章节生成后统一执行自评与格式化最终化。
  - 旧场景写作路径也接入固定专著提示词作为兼容兜底。

- `libriscribe/prompts/templates/chapter_writer.yml`
  - 外部章节写作模板改为完整学术专著提示词版本。

- `libriscribe/src/libriscribe/workflow/nodes.py`
  - 工作流写作节点接入固定专著提示词与自评最终化。
  - 工作流编辑节点补齐固定专著提示词与 `finalize_academic_chapter` 最终化。

- `libriscribe/src/libriscribe/agents/editor.py`
  - 传统章节编辑 Agent 接入固定专著提示词。
  - 编辑结果保存前统一执行自评最终化。

- `libriscribe/src/libriscribe/agents/style_editor.py`
  - 风格润色 Agent 接入固定专著提示词。
  - 润色结果保存前统一执行自评最终化。

- `libriscribe/src/libriscribe/agents/formatting.py`
  - 整书格式化路径接入固定专著提示词。
  - 格式化结果统一执行首行缩进规范化。

- `libriscribe/src/libriscribe/utils/prompt_integration.py`
  - 外部模板集成层对章节、编辑、风格、格式化、场景生成类模板默认叠加固定专著提示词，后续新增相关模板也会自动继承该规范。

- `libriscribe/src/libriscribe/export/pdf_export.py`
  - 同步保留 PDF 字体与空页处理修复，避免 TTC 字体集合和页索引异常影响导出。
