# 大纲页面 ChapterSection 类型注解运行错误修复

## 摘要

修复大纲页渲染时报错：`name 'ChapterSection' is not defined`。

原因是新增的页面内兜底函数使用了运行期会求值的类型注解 `list[ChapterSection]`，但 `ChapterSection` 只在 `_parse_outline_text()` 局部导入，并未在 `render_outline_page()` 作用域内定义，导致 Streamlit 渲染页面时直接触发 `NameError`。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 将 `_fill_missing_section_words_for_display(sections: list[ChapterSection])` 改为 `_fill_missing_section_words_for_display(sections: list[Any])`，避免页面渲染期依赖未导入类型。

## 验证

已运行：

```bash
python -m pytest tests/test_commercial_routes.py -q
```

结果：`66 passed in 3.20s`。
