# 章节生成 Errno22 路径修复

## 摘要
- 修复章节/小节生成时项目目录误带多层引号、中文引号，或 `project_dir` 误保存为 `knowledge_base.json` 文件路径导致的 Windows `[Errno 22] Invalid argument`。
- 增加统一路径清理与项目目录推导函数，生成前自动把项目目录恢复为真实目录。
- 后台章节生成遇到异常时改为返回更完整的文件系统错误提示，避免只显示裸 `Errno 22`。
- 增加回归测试覆盖引号清理、JSON 文件路径误用修复和小节输出路径构造。

## 变更文件
- `libriscribe/src/libriscribe/web/app.py`
  - 增强 `_clean_path_text()`：支持多层普通引号、中文引号和 BOM/空白清理。
  - 新增 `_safe_project_dir_from_paths()`：当 `project_dir` 为空或误指向 `knowledge_base.json` 时，自动推导真实项目目录。
  - 更新 `_resolve_chapter_output_paths()`：统一使用安全项目目录，写回修复后的 `project.project_dir`，并预检输出路径不是目录。
  - 更新 `_bg_write_chapter()`、实时单章/全书生成入口：生成前统一规范化项目目录和项目文件路径。
  - 后台章节生成异常返回 `_format_generation_error()` 的可读提示。
- `libriscribe/tests/test_chapter_output_paths.py`
  - 增加中文/嵌套引号路径清理测试。
  - 增加 `project_dir` 误保存为 `knowledge_base.json` 文件路径的修复测试。
