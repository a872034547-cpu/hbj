# 好编辑 2.0 阶段 0/1：资料库与引用链最小实现

时间：2026-05-10

## 摘要

本次继续推进 2.0 升级，从规划文档进入最小可用实现。重点完成资料来源、证据片段、引用核验基础字段和资料库/RAG 中心页面，为后续“可信资料链”和“引用核验中心”打基础。

## 已完成

1. 扩展项目数据模型：
   - 新增 `SourceDocument`：记录资料来源文档、文件 hash、索引时间、切片数量等。
   - 新增 `EvidenceChunk`：记录可追溯证据片段、来源文档、chunk hash、片段文本等。
   - 扩展 `Citation`：增加 `id`、`evidence_chunk_id`、`style`、`doi`、`isbn`、`url`、`status` 等字段。
   - 新增 `TaskLog` 和 `BookReviewReport`，为后续任务断点恢复和全书质量报告预留结构。
   - 为旧项目 JSON 加入迁移默认值，保持兼容。

2. 增强 RAG 元数据：
   - `DocumentLoader` 现在为每个文档生成 `source_id`、`file_hash`。
   - 每个分块生成稳定的 `evidence_id`、`chunk_hash`。
   - 分块元数据增加 `char_count`、`total_chunks` 等可视化信息。

3. 增强向量库写入稳定性：
   - `VectorStore` 增加 metadata 清洗逻辑，避免 ChromaDB 因复杂对象元数据索引失败。

4. 新增资料库/RAG 中心入口：
   - 侧边栏新增“资料库/RAG”。
   - 新页面展示资料来源数、证据片段数、引用记录数、未核验引用数。
   - 支持上传并索引资料。
   - 显示已索引资料、证据片段样例。
   - 支持输入查询词进行 RAG 检索测试，展示 evidence_id、source_id、chunk_index 和片段内容。

5. 去小说化文案微调：
   - 侧边栏项目状态从“角色”改为“资料/证据片段”。
   - i18n 中将部分角色/场景文案标记为旧版兼容。
