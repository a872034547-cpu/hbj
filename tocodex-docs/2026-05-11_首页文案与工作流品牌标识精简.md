# 首页文案与工作流品牌标识精简

## 摘要

根据界面反馈，移除了首页和工作流页中偏技术化、品牌化的展示文案，避免页面显示“一小时写书 Agent”“Libriscribe 2.0”“项目组合”等不需要的标题与角标。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - `render_workspace_page()` 不再显示“① 选题与项目 / 一小时写书 Agent”头部。
  - `render_projects_page()` 不再显示“项目组合 / 管理专著项目组合...”头部，直接进入项目创建/加载界面。
  - `_render_business_hero()` 默认不再显示 `Libriscribe 2.0` 角标，只有显式传入 badge 时才展示。
  - `render_pipeline_page()` 将“一小时写书 Agent 工作台”改为“一小时写书工作台”，角标改为“写作工作流”。

- `libriscribe/src/libriscribe/web/i18n.py`
  - 中文导航 `nav_projects` 从“项目组合”改为“项目”。

- `libriscribe/src/libriscribe/services/pipeline_service.py`
  - 内部文档字符串去掉“一小时写书 Agent”表述，改为“写作工作流”。
