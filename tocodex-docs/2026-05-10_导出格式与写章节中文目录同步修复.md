# 导出格式与写章节中文目录同步修复

## 摘要

本次调整让最终导出的 Word 文档尽量贴近用户提供的参考文档 `4.14初稿《智慧工地建设与工程现场数字化管理》.docx`：统一 A4 页面、左右/上下页边距、中文专著标题层级、正文 10.5 磅与两字符缩进。PDF 导出同步参考 Word 的页边距、标题字号和正文缩进。

同时，“写章节”页的写作单元目录不再显示内部数字编号 `1.1 / 1.1.1 / 1.1.1.1`，改为与大纲一致的中文层级：`第一节 / 一、 / （一）`，内部仍保留原 `section_number` 用于生成和文件定位。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 新增中文大纲编号展示辅助函数。
  - 写章节页写作单元标题改为中文层级显示。

- `libriscribe/src/libriscribe/export/docx_export.py`
  - 新增参考 Word 版式应用逻辑。
  - 设置 A4、上下 2.54cm、左右 3.17cm。
  - 设置 Title、Heading 1/2/3/4、Normal、Body Text 样式。
  - 正文段落使用 10.5 磅、两字符首行缩进、两端对齐。

- `libriscribe/src/libriscribe/export/pdf_export.py`
  - PDF 导出同步参考 Word 的页边距、标题层级字号和正文缩进。
  - ReportLab 与 FPDF 兜底路径均做了相应格式调整。

- `libriscribe/tests/test_commercial_routes.py`
  - 增加写章节中文层级标签回归测试。

- `libriscribe/tests/test_export_and_quality_gate_services.py`
  - 增加 DOCX 参考版式回归测试。
