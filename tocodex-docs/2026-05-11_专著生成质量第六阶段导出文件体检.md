# 专著生成质量第六阶段：导出文件体检

## 摘要

本阶段把导出质量保障从“导出前正文风险检查”继续推进到“导出后产物体检”。导出服务在调用具体 DOCX / PDF / PPTX / LaTeX 导出器之后，会立即确认产物文件真实存在、后缀正确且大小不是空壳文件，从而避免页面提示导出成功但实际文件缺失或为空。

## 主要改动

- 在 `ExportService` 中新增 `validate_export_file()`。
- 为 DOCX / PDF / PPTX / LaTeX 设置最低文件大小阈值。
- 所有 `export_docx()`、`export_pdf()`、`export_pptx()`、`export_latex()` 返回前统一执行导出后体检。
- 若导出器未生成文件、文件过小或后缀异常，抛出明确错误。
- 更新导出服务测试，使 fake exporter 也写入模拟产物，确保测试覆盖真实产物存在性校验。
- 新增缺失文件和过小文件的导出体检回归测试。

## 修改文件

- `libriscribe/src/libriscribe/services/export_service.py`
  - 新增 `MIN_EXPORT_BYTES`。
  - 新增 `validate_export_file()`。
  - 新增 `_ensure_valid_export()`。
  - 四类导出方法返回前统一调用导出后体检。
- `libriscribe/tests/test_export_and_quality_gate_services.py`
  - fake 导出器现在会写入模拟输出文件。
  - 新增 `test_export_service_validates_missing_or_tiny_outputs()`。
