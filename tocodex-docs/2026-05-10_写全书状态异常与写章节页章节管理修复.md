# 写全书状态异常与写章节页章节管理修复

## 摘要

修复“生成全书”在写章节页报错的问题：Streamlit 不允许在 `selectbox` 控件实例化后继续修改同名 `session_state` key。现在全书生成不再写入编辑器章节选择控件的 state，而是使用独立状态记录当前生成章节。

同时根据反馈，在“写章节”页面增加章节管理能力：支持删除当前章、清空全部章节，并在大纲重解析后刷新章节选择控件 key，避免旧章节列表缓存导致写章节页不同步。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - `_generate_book_with_ai` 不再修改 `editor_selected_idx`，改为写入独立的 `book_generation_current_chapter`。
  - `render_editor_page` 的章节选择控件 key 加入大纲解析版本和章节签名，重解析后自动刷新。
  - 写章节页新增“章节管理”区域，支持删除当前章和清空全部章节，同时删除对应 `chapter_N.md` 文件。
  - `_parse_outline_text` 成功重建章节后递增 `outline_parse_version`，强制写章节页同步新章节列表。

- `libriscribe/tests/test_commercial_routes.py`
  - 新增测试，确保 `_generate_book_with_ai` 不再写入已实例化 widget key `editor_selected_idx`。
