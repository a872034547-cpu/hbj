# 低风险去重、RAG 性能与导出统一实施备忘录

## 摘要

本次按已确认方案完成低风险实施：集中中文章节/目录标签工具，统一导出章节标题去重逻辑，并修复空向量库检索时反复加载本地 embedding 模型的问题。未改动主生成循环、项目数据结构、页面路由和用户操作流程。

## 主要变更

- 在中文标签工具中新增统一的四级目录标签格式化与章标题去重函数。
- 让章节写作 Agent 的目录标签格式化转调共享工具，避免重复中文数字逻辑。
- 让 DOCX/PDF/LaTeX 导出器与 Web 导出预处理共用同一章标题去重函数，兼容 `第一章`、`第 1 章`、`Chapter 1`。
- 为本地 sentence-transformers embedding 模型增加进程内缓存，减少同一模型重复加载。
- 调整 Retriever / VectorStore 初始化策略：空向量库检索时直接返回，不初始化 embedding provider，避免无资料时每小节都加载权重。
- 增加回归测试覆盖共享标题去重和空向量库跳过 embedding 查询。
