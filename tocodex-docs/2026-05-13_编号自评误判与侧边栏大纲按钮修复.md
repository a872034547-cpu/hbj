# 编号自评误判与侧边栏大纲按钮修复

## 摘要

本次修复了章节自评中“编号连续性与一致性”在正文缺少章标题时被误判为 `0/10` 的问题，并移除了侧边栏会直接触发 AI 生成大纲的一键按钮，避免用户绕过大纲页配置与确认流程。

## 变更文件

- `libriscribe/src/libriscribe/utils/academic_prompt.py`
  - 新增中文学术层级编号识别逻辑。
  - 自评不再强制要求正文包含“第X章”，可识别“第一节”“一、”“（一）”等正文层级标题。
  - 保留对 `第0章`、`第0节`、`Section 1:` 等异常编号的扣分判断。

- `libriscribe/src/libriscribe/web/app.py`
  - 移除侧边栏“下一步：生成/整理大纲”按钮。
  - 删除侧边栏中直接调用 `_generate_outline_with_ai(project)` 的路径。
  - 保留“保存当前项目”和导出入口。

- `libriscribe/tests/test_commercial_routes.py`
  - 增加章节自评编号识别回归测试。
  - 增加侧边栏不再暴露一键生成大纲按钮的回归测试。

## 验证

已运行定向测试：

```cmd
cd libriscribe && set PYTHONPATH=src && python -m pytest tests/test_commercial_routes.py -k "self_assess_chapter_accepts_body_level_chinese_numbering_without_chapter_heading or sidebar_does_not_expose_one_click_outline_generation or sidebar_exposes_formatted_word_export_and_structured_adapter" -q
```

结果：`3 passed, 97 deselected`。
