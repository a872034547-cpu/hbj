# AI 模型配置默认模板与选择提示更新

## 摘要

- 将内置 AI 模型默认模板升级到最新配置：OpenAI 默认 `gpt-5.5`，OpenRouter 默认 `openai/gpt-5.5`，DeepSeek 默认 `deepseek-v4-pro`，并同步更新 Claude、Gemini、Mistral 默认建议。
- 在模型配置页新增平台级引导：选择不同模型平台时展示 API Key 获取入口、模型文档入口、API Base 填写规则、必填字段和注意事项。
- 增加旧官方空档案迁移逻辑：仅刷新旧内置官方默认模型，不覆盖用户自定义档案和已手动编辑的密钥配置。
- 同步更新底层 `LLMClient` 和 `Settings` 的默认模型，避免前端模板与后端兜底模型不一致。
- 增加测试覆盖默认模型迁移和平台引导文案。

- `libriscribe/src/libriscribe/web/app.py`
  - 更新 `DEFAULT_PROVIDER_MODELS`。

  - 在模型档案归一化时迁移旧官方默认模型。

  - 更新 OpenRouter、初稿模型和润色模型默认值。
- `libriscribe/tests/test_commercial_routes.py`
  - 增加模型默认模板与平台引导测试。
