# Web 提示词范文与中文专著大纲生成流程重构

## 摘要

本次改造解决两个核心问题：

1. Web 提示词页面主视图继续出现英文模板名、缺少范文说明的问题。
2. AI 大纲生成缺少“先整体框架思考、再逐章写作思路、章际逻辑一致、可单章生成/修改”的专著策划流程。

## 主要变更

- 为所有全局提示词补充中文范文/示例字段，由后端 `PromptService.list_all_global_prompts()` 统一返回。
- 将 `outliner` 从旧英文小说大纲模板切换为中文专著大纲默认提示词。
- Web 提示词界面主视图隐藏英文键名，只展示中文名称、中文用途、范文/示例和可编辑提示词；英文键名、原始名称、文件来源移动到“高级信息”。
- 大纲生成后端实际读取全局 `outliner` 提示词，确保前端编辑后对 AI 大纲生成生效。
- AI 大纲生成流程升级为：内部整体框架思考 → 全书章际逻辑 → 每章写作职责 → “章—节—一、—（一）—写作思路”格式输出。
- 新增“单章生成/修改”模式，可选择某一章单独生成或重写，并合并回全书大纲。
- 大纲解析器新增对中文目录格式的支持：`第一节`、`一、`、`（一）`、`写作思路：`。
