# LibriScribe 小白安装和使用文档（Windows 版）

> 适合完全没有 Python 项目经验的用户。按本文档从上到下执行即可启动网页写书系统。
>
> 项目目录示例：`D:\weidong\libriscribe`
>
> 本文所有命令默认在 Windows 10/11 的“命令提示符 CMD”中执行。

---

## 0. 你最终会得到什么

安装完成后，可以在浏览器打开：

```cmd
http://localhost:8501
```

进入网页端写书系统，完成：

1. 创建写书项目。
2. 配置 AI 模型。
3. 上传资料。
4. 生成大纲。
5. 生成章节正文。
6. 生成前言、结语、参考文献。
7. 导出 Word、Word（带格式）、PDF、PPTX 等文件。

---

## 1. 安装前必须准备的环境

### 1.1 安装 Python 3.10 或 3.11

本项目是 Python 项目。建议安装 Python 3.10 或 3.11。

#### 第一步：查看电脑是否已经安装 Python

打开 CMD，输入：

```cmd
python --version
```

如果看到类似下面内容，说明已经安装：

```cmd
Python 3.10.11
```

或：

```cmd
Python 3.11.8
```

如果提示：

```cmd
'python' 不是内部或外部命令，也不是可运行的程序
```

说明没有安装 Python，需要继续下面步骤。

#### 第二步：使用 winget 安装 Python

Windows 10/11 通常自带 `winget`。在 CMD 中执行：

```cmd
winget install Python.Python.3.11
```

安装完成后，关闭 CMD，再重新打开一个新的 CMD。

再次检查：

```cmd
python --version
```

#### 第三步：检查 pip 是否可用

```cmd
python -m pip --version
```

如果能看到版本号，例如：

```cmd
pip 24.0 from ...
```

说明 pip 可用。

如果 pip 不可用，执行：

```cmd
python -m ensurepip --upgrade
python -m pip install --upgrade pip
```

---

### 1.2 安装 Git

Git 用来下载项目代码。

#### 第一步：查看是否已经安装 Git

```cmd
git --version
```

如果看到类似：

```cmd
git version 2.45.0.windows.1
```

说明已安装。

#### 第二步：如果没有安装，使用 winget 安装

```cmd
winget install Git.Git
```

安装完成后关闭 CMD，重新打开 CMD，再检查：

```cmd
git --version
```

---

### 1.3 安装 Visual Studio Code（推荐）

VS Code 不是必须，但推荐安装，方便打开项目文件、查看日志和修改配置。

```cmd
winget install Microsoft.VisualStudioCode
```

安装完成后检查：

```cmd
code --version
```

如果 `code` 命令不可用，也不影响运行项目，可以从开始菜单打开 VS Code。

---

### 1.4 安装 Microsoft Word 或 WPS（用于查看 Word 导出）

导出的 `.docx` 文件需要 Word 或 WPS 打开。

如果已安装 Microsoft Office 或 WPS，可跳过。

WPS 可用 winget 安装：

```cmd
winget install Kingsoft.WPSOffice.CN
```

---

### 1.5 可选：安装 Pandoc（用于部分 PDF/文档转换能力）

项目内 Word 导出不强制依赖 Pandoc，但部分格式转换可能用到。

```cmd
winget install JohnMacFarlane.Pandoc
```

检查：

```cmd
pandoc --version
```

## 3. 创建 Python 虚拟环境

虚拟环境用于隔离依赖，避免污染系统 Python。

### 3.1 在项目根目录创建虚拟环境

确保当前目录是：

```cmd
D:\weidong\libriscribe
```

执行：

```cmd
python -m venv .venv
```

执行后，项目目录会出现 `.venv` 文件夹。

---

### 3.2 激活虚拟环境

在 CMD 中执行：

```cmd
.venv\Scripts\activate
```

激活成功后，命令行前面会出现：

```cmd
(.venv) D:\weidong\libriscribe>
```

只要看到 `(.venv)`，说明虚拟环境已经启用。

---

### 3.3 升级 pip

```cmd
python -m pip install --upgrade pip setuptools wheel
```

## 4. 安装项目依赖

### 4.1 推荐安装方式：按 requirements.txt 安装

在已激活虚拟环境的 CMD 中执行：

```cmd
python -m pip install -r requirements.txt
```

这一步可能需要几分钟。

如果网络较慢，可以使用清华源：

```cmd
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 4.2 安装当前项目为可编辑模式

```cmd
python -m pip install -e .
```

如果网络慢，也可以：

```cmd
python -m pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 4.3 如果安装 unstructured 很慢或失败怎么办

`unstructured[all-docs]` 依赖较多，可能安装时间较长。

先重试：

```cmd
python -m pip install "unstructured[all-docs]>=0.15.0" -i https://pypi.tuna.tsinghua.edu.cn/simple
```

然后再执行：

```cmd
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果只是先体验网页写书，不做复杂 PDF/Word 资料解析，可以先安装核心依赖：

```cmd
python -m pip install typer openai python-dotenv pydantic pydantic-settings beautifulsoup4 requests markdown fpdf anthropic google-generativeai tenacity rich pick tavily-python chromadb sentence-transformers langgraph langchain-core python-docx pypandoc reportlab python-pptx streamlit pytest -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 5. 配置 AI 模型 API Key

系统需要 AI 模型才能生成大纲和正文。

你可以使用：

- OpenAI
- DeepSeek
- Claude
- Gemini
- Mistral
- OpenAI-compatible 自定义接口

推荐小白优先用网页里的“模型设置”配置，不建议手动改代码。

---

### 5.1 方式一：在网页中配置模型（推荐）

启动项目后，在左侧进入：

```text
模型设置
```

然后填写：

```text
模型供应商
API Base
API Key
模型名称
```

常见自定义 OpenAI-compatible 配置示例：

```text
模型供应商：custom
API Base：https://你的接口地址/v1
API Key：你的密钥
模型名称：你的模型名
```

填写后点击测试连接或保存。

---

### 5.2 方式二：使用 .env 文件配置

在项目根目录 `D:\weidong\libriscribe` 新建 `.env` 文件。

CMD 命令：

```cmd
copy .env.example .env
```

然后用记事本打开：

```cmd
notepad .env
```

按你使用的平台填写，例如：

```env
OPENAI_API_KEY=你的OpenAI密钥
DEEPSEEK_API_KEY=你的DeepSeek密钥
CLAUDE_API_KEY=你的Claude密钥
GOOGLE_AI_STUDIO_API_KEY=你的Gemini密钥
MISTRAL_API_KEY=你的Mistral密钥
```

保存后关闭记事本。

## 7. 第一次使用：完整写书流程

### 7.1 创建项目

打开网页后，进入左侧：

```text
① 项目
```

填写：

```text
项目名称：例如 我的第一本专著
书名：例如 人工智能赋能高职图书馆阅读推广研究
类型：专著
目标读者：高校教师、图书馆工作人员、研究人员
描述：说明这本书要解决什么问题
```

点击创建项目。

项目会保存在：

```cmd
D:\weidong\libriscribe\projects\你的项目名
```

---

### 7.2 配置模型

进入：

```text
模型设置
```

填写你的模型 API 信息。

如果使用自定义兼容接口，注意：

```text
API Base 必须通常以 /v1 结尾
API Key 不能有中文、空格、换行
模型名称必须和接口支持的模型名一致
```

配置完成后保存。

---

### 7.3 上传资料

进入：

```text
② 资料与检索
```

可以上传：

```text
PDF
Word DOCX
Excel
TXT
Markdown
```

上传资料的作用：

1. 给 AI 提供真实依据。
2. 减少胡编乱造。
3. 让章节写作能引用资料。

小白建议：

```text
先上传 3-10 份和书稿主题强相关的资料
```

---

### 7.4 生成或粘贴大纲

进入：

```text
③ 大纲与结构
```

你可以选择：

1. 手动粘贴大纲。
2. 点击 AI 生成全书大纲。
3. 对单章大纲二次修改。

推荐大纲格式：

```text
第一章 绪论
第一节 研究背景
一、现实背景
（一）政策牵引
（二）技术基础
二、研究意义
（一）理论意义
（二）实践意义

第二章 相关理论基础
第一节 人工智能基础
一、生成式人工智能
（一）技术演进
（二）应用边界
```

保存或解析大纲后，系统会生成章节结构。

---

### 7.5 生成章节正文

进入：

```text
⑤ 正文编辑
```

选择某一章，然后点击：

```text
AI 生成章节
```

或选择具体小节逐节生成。

建议小白操作顺序：

1. 先生成第一章。
2. 检查内容是否符合风格。
3. 再继续生成后续章节。
4. 不要一开始就一次性生成全书，先确认模型配置和风格都正确。

---

### 7.6 生成前言、结语、参考文献

进入：

```text
⑤ 正文编辑
```

找到前言、结语、参考文献区域。

可以设置：

```text
前言预期字数
结语预期字数
参考文献数量
参考文献年份范围
参考文献格式
```

例如：

```text
前言：900 字
结语：900 字
参考文献：30 条
年份：2019-2026
格式：GB/T 7714-2015
```

点击 AI 生成。

## 8. 导出 Word、PDF、PPTX

进入左侧：

```text
⑥ 审校与交付
```

或在侧边栏找到导出区域。

常用导出：

```text
DOCX：普通 Word 导出
Word（带格式）导出：专业封面、目录、页眉页脚、标题样式
PDF：PDF 文件
PPTX：汇报 PPT
Markdown：原始文本
```

---

### 8.1 推荐使用“Word（带格式）导出”

这个导出会生成更正式的专著格式，包括：

1. 封面。
2. 目录。
3. 前言。
4. 正文章节。
5. 结语。
6. 参考文献。
7. 页眉页脚。
8. 中文标题层级。

标题层级示例：

```text
第一章 绪论
第一节 研究背景
一、现实背景
（一）政策牵引
（二）技术基础
```

---

### 8.2 单独使用脚本导出结构化 JSON 为 Word

如果你已经有结构化 JSON 文件，可以直接用脚本导出。

命令格式：

```cmd
python scripts\export_structured_json_to_docx.py 输入文件.json 输出文件.docx
```

示例：

```cmd
python scripts\export_structured_json_to_docx.py data\book.json output\book.docx
```

如果输出目录不存在，先创建：

```cmd
mkdir output
```

再执行：

```cmd
python scripts\export_structured_json_to_docx.py data\book.json output\book.docx
```

## 11. 常见问题和解决命令

### 11.1 提示 python 不是内部或外部命令

原因：Python 没装或没加入 PATH。

解决：

```cmd
winget install Python.Python.3.11
```

关闭 CMD，重新打开，再执行：

```cmd
python --version
```

---

### 11.2 pip 安装很慢

使用清华源：

```cmd
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 11.3 streamlit 不是内部或外部命令

不要直接运行 `streamlit`，改用：

```cmd
python -m streamlit run src\libriscribe\web\app.py
```

如果仍然失败，重新安装：

```cmd
python -m pip install streamlit -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 11.4 运行时报 ModuleNotFoundError

例如：

```cmd
ModuleNotFoundError: No module named 'xxx'
```

先确认已激活虚拟环境：

```cmd
.venv\Scripts\activate
```

再安装依赖：

```cmd
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install -e .
```

---

### 11.5 网页打不开 localhost:8501

先看 CMD 里是否有：

```cmd
Local URL: http://localhost:8501
```

如果没有，说明服务没启动成功。

重新启动：

```cmd
cd D:\weidong\libriscribe
.venv\Scripts\activate
python -m streamlit run src\libriscribe\web\app.py
```

如果端口被占用：

```cmd
python -m streamlit run src\libriscribe\web\app.py --server.port 8502
```

然后打开：

```cmd
http://localhost:8502
```

---

### 11.6 AI 生成失败或生成空内容

常见原因：

1. API Key 填错。
2. API Base 填错。
3. 模型名填错。
4. 账户余额不足。
5. 当前模型没有权限。
6. API Key 里复制进了空格、换行或中文字符。

处理步骤：

1. 进入网页左侧“模型设置”。
2. 检查 API Base、API Key、模型名。
3. 删除 API Key 前后的空格。
4. 保存后重新测试连接。
5. 如果终端提示 `insufficient_user_quota`，说明账户额度不足，需要充值或换模型。

---

### 11.7 Word 导出没有目录页码

Word 目录是动态域，需要在 Word/WPS 里更新。

操作：

1. 打开导出的 Word。
2. 鼠标右键点击目录。
3. 选择“更新域”。
4. 选择“更新整个目录”。

---

### 11.8 Word 导出四级标题（一）（二）不显示

请确认正文 Markdown 使用了四级标题格式：

```markdown
## 第一节 研究背景

### 一、现实背景

#### （一）政策牵引
正文内容

#### （二）技术基础
正文内容
```

然后使用：

```text
Word（带格式）导出
```

## 17. 小白注意事项

1. 所有命令都建议在 CMD 中执行，不要混用多个终端。
2. 每次运行项目前，先执行 `.venv\Scripts\activate`。
3. 安装依赖失败时，优先换国内源重试。
4. AI 生成空内容时，优先检查 API Key、余额、模型名。
5. 导出 Word 后，目录需要在 Word/WPS 中手动“更新域”。
6. 不要把 API Key 发给别人，也不要截图泄露。
7. 项目生成内容仍需人工审校，不建议直接作为最终出版稿。
