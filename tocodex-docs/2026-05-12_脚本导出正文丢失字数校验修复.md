# 脚本导出正文丢失字数校验修复

## 摘要

修复网页 DOCX 与“Word（带格式）”导出缺少正文完整性确认的问题。现在导出前会统计待导出正文约多少字，导出后会读取生成的 DOCX 可见文本并再次统计字数；若导出后字数明显低于导出前，会在页面提示疑似正文丢失风险。

同时为结构化 JSON 专业 Word 导出脚本增加正文收集与字数统计辅助函数，确保四级标题下正文也纳入导出前统计。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 新增导出前正文合并与字数统计函数。
  - 新增导出后读取 DOCX 可见文本的字数校验函数。
  - 普通 DOCX 与 Word（带格式）导出均展示导出前/后字数。
  - 过滤结构化参考文献中的“参考文献”标题，避免重复进入导出数据。

- `libriscribe/scripts/export_structured_json_to_docx.py`
  - 新增 `count_export_words()`。
  - 新增 `collect_structured_body_text()`。
  - `export_json_data_to_docx()` 记录最近一次导出前正文统计值 `last_body_word_count`。

- `libriscribe/tests/test_export_and_quality_gate_services.py`
  - 增加结构化导出正文统计、四级正文保留、函数返回值等断言。
