# 独立 JSON 专著内容导出 Word 脚本

## 摘要

新增一个独立命令行脚本，用于把已准备好的结构化 JSON 专著内容导出为格式统一的 Word `.docx` 文件。该脚本只位于 `scripts/` 目录，不接入现有文章生成链路、网页功能或默认导出流程，因此不会影响生成文章和其他功能。

## 变更文件

- `libriscribe/scripts/export_structured_json_to_docx.py`
  - 使用 `python-docx` 读取结构化 JSON 并生成 `.docx`。
  - 在 `initialize_styles()` 中强制覆盖 `Normal`、`Heading 1`、`Heading 2`、`Heading 3`、`Reference` 等样式。
  - 正文固定宋体 / Times New Roman、小四、固定 22 磅行距、首行缩进 24 磅。
  - 章标题、节标题、小节标题分别按黑体、字号、加粗、对齐、段前段后和大纲级别写死。
  - 参考文献使用悬挂缩进 24 磅。
  - 写入前清理 Markdown、HTML、列表、链接等格式标记，只保留纯文本。
  - 导出前扫描所有段落 run，并自动修正字体设置。
  - 命令行接收 JSON 文件路径，默认输出同名 `.docx`，也支持 `-o/--output` 指定输出路径。

## 验证

- 已运行：`python -m py_compile scripts\\export_structured_json_to_docx.py`
- 结果：语法检查通过。
