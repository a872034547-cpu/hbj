# 章节生成实时反馈与错误隔离修复

## 摘要

本次修复针对用户反馈的“按章生成没有动静”“错误不要写进章节正文”“需要看到实时生成效果”。章节写作现在在当前页面实时展示进度和正文动态预览，模型返回异常、网页错误页、空响应时不会写入章节正文。

## 主要变化

- 章节生成与小节生成改为页面实时执行，生成过程中显示：
  - 当前小节进度。
  - 实时正文预览。
  - 完成或失败提示。
- `ChapterWriterAgent` 支持 `progress_callback` 和 `content_callback`，可把生成过程回传到页面。
- `LLMClient` 新增 `stream_content()`：
  - OpenAI / OpenRouter / 自定义 OpenAI 兼容平台支持流式输出。
  - Claude 支持流式输出。
  - Google / DeepSeek / Mistral 暂降级为一次性返回，但仍有明确页面状态。
- 模型异常输出不会写入正文：
  - 空响应。
  - HTML/网页错误页。
  - 错误占位文本。
  - 只有标题没有正文的结果。
- 写作失败时页面显示错误原因，不污染章节 Markdown 文件。
