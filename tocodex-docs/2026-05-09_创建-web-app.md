## 功能概要

1. **页面配置**: `page_title='Libriscribe - AI Book Writer'`, `page_icon='📚'`, `layout='wide'`, `initial_sidebar_state='expanded'`
2. **Session State 管理**: `project_data`, `current_page`, `llm_client`, `project_dir`, `project_file`, `chat_history`, `notification`
3. **侧边栏导航**: Logo/标题 + 5 个页面（Dashboard, Outline, Editor, Chat, Settings）+ 项目信息 + 保存/导出按钮（DOCX, LaTeX, PDF）
4. **Dashboard 页面**: 创建新项目表单 / 加载已有项目列表 / 项目概览
5. **Outline 页面**: 大纲编辑 / AI 生成大纲 / 章节管理（增删改）
6. **Editor 页面**: 章节内容编辑 / AI 写作 / AI 评审 / 场景列表 / 术语表参考
7. **Chat 页面**: 聊天式 AI 助手，带项目上下文
8. **Settings 页面**: 基本信息 / 术语表管理 / 风格指南 / RAG 文档管理 / 危险操作
9. **辅助函数**: `init_session_state()`, `load_project()`, `save_project()`, `get_llm_client()`, `create_new_project()`, `list_existing_projects()`
10. **导出功能**: DOCX（python-docx）、LaTeX、PDF（LaTeX 编译）

## 运行方式

```bash
cd libriscribe
streamlit run src/libriscribe/web/app.py
```
