# 好编辑平台功能特点宣传文案与快速上手教程

## 一、平台宣传文案

### 标题
好编辑：面向中文专著、教材与研究报告的一小时写书 Agent 工作台

### 一句话介绍
好编辑把“选题策划、资料入库、大纲生成、逐章写作、审校核验、导出交付”串成一条清晰流程，让作者用 AI 更快完成结构完整、资料可追溯、可继续人工打磨的中文长文稿。

### 核心卖点

1. **一条主线写完整本书**
   - 按“项目 → 资料 → 大纲 → 写章节 → 审校 → 导出 → 模型设置”组织流程。
   - 用户不用理解复杂工程术语，只需要按写书顺序推进。

2. **中文专著大纲友好**
   - 支持“第一章 / 第一节 / 一、 / （一） / 写作思路”这类中文专著目录格式。
   - 可把当前大纲一键重建为章节与写作单元，重构结果会明确显示。
   - 支持手动新增、修改、删除章节，方便按作者意图微调结构。

3. **资料驱动，而不是空想写作**
   - 支持上传资料、AI 资料助手、检索词整理、资料缺口分析和大纲前头脑风暴。
   - 支持 OpenAlex 学术文献检索与引用候选整理。
   - 写大纲和正文时可复用资料库与内部分析记录，降低“凭空编造”的风险。

4. **逐章生成可见可控**
   - 单章、小节和全书写作都能看到实时进度。
   - 全书生成按章节顺序推进，当前生成到哪一章清晰可见。
   - 生成失败时尽量隔离错误，避免把错误页、异常文本写入正文。

5. **导出正文更干净**
   - 导出前自动清理评分、AI 评分、质量自检、评审结果、字数偏差等过程信息。
   - 最终 DOCX / PDF / LaTeX / PPTX 更接近可交付书稿，而不是调试日志。

6. **多模型配置，适配内外部环境**
   - 支持官方平台和自定义兼容接口。
   - 可配置 GPT、Claude、DeepSeek、通义、智谱、月之暗面等模型档案。
   - 适合个人写作、团队内网部署和机构知识生产场景。

### 适合谁使用

- 想把研究积累整理成专著、教材、白皮书或行业报告的作者。
- 需要快速搭建章节结构、统一写作风格的编辑团队。
- 希望把本地资料、学术文献和 AI 写作结合起来的知识工作者。
- 需要在内网或私有环境中使用大模型辅助写作的组织。

### 推广短文案

好编辑不是简单的 AI 聊天框，而是一套围绕中文长文稿生产设计的写书工作台。你可以先输入项目定位，再把资料、文献和内部分析沉淀到资料库，随后让 AI 生成可解析的中文专著大纲，并按章节逐步完成正文。平台保留人工可控的编辑入口，也提供审校、引用核验和多格式导出能力，帮助作者把零散想法与资料快速组织成一本结构清晰、可继续打磨的书稿。

## 二、快速上手教程

### 第 1 步：创建项目

1. 打开“① 项目”。
2. 填写书名、方向、目标读者、用途和大致字数。
3. 保存项目后，确认侧边栏显示当前项目名称。

建议：项目描述不要只写一句话，尽量说明“写给谁、解决什么问题、希望形成什么成果”。

### 第 2 步：整理资料

1. 进入“② 资料”。
2. 上传 PDF、DOCX、TXT、Markdown 等参考资料。
3. 使用“AI 资料助手”按顺序生成：
   - 检索词；
   - 整理检索结果；
   - 分析资料缺口；
   - AI 补充资料；
   - 大纲前头脑风暴。
4. 需要学术文献时，可使用 OpenAlex 检索并导入候选引用。

建议：资料助手生成的重要结果要保存到资料库，这样后续大纲和正文更容易引用到。

### 第 3 步：生成或粘贴大纲

1. 进入“③ 大纲”。
2. 可以选择 AI 生成全书大纲，也可以粘贴自己的大纲。
3. 推荐中文专著格式：

```markdown
第一章 智慧工地建设总论（总字数 10000字）
第一节 工程现场数字化转型的时代背景（约3000字）
一、行业发展与政策驱动
（一）智慧工地的概念边界
写作思路：先界定智慧工地，再说明数字化管理价值。
```

4. 点击“按当前大纲重建章节”或“用当前大纲重建章节”。
5. 查看页面提示的“已重建 X 章”和下方章节列表。
6. 如果结构不符合预期，可以删除单章或清空全部章节后重新解析。

### 第 4 步：写章节或生成全书

1. 进入“④ 写章节”。
2. 在顶部选择要查看或生成的章节。
3. 点击“AI 写作”生成当前章。
4. 如果只想写一个最小写作单元，可在下方写作单元列表中点击“生成此小节”。
5. 点击“生成全书”后，平台会按章节顺序逐章生成，并显示当前章进度和正文预览。

建议：第一次生成全书前，先试写一章，确认模型、提示词、资料质量和文风符合预期。

### 第 5 步：审校与优化

1. 进入“⑥ 审校”查看质量与引用风险。
2. 在写章节页面可以对单章进行 AI 审校或局部优化。
3. 评分、自检和评审结果仅用于过程参考，不会作为最终正文导出。

### 第 6 步：导出交付

1. 进入“⑦ 导出”。
2. 选择 DOCX、PDF、LaTeX 或 PPTX。
3. 导出前系统会自动清理正文中的评分、自检、评审和字数偏差等过程信息。
4. 下载生成文件后，再进行人工终审和排版检查。

## 三、推荐工作流

最稳妥的顺序是：

**创建项目 → 资料入库 → AI 资料助手整理 → 大纲前头脑风暴 → 生成/粘贴大纲 → 重建章节 → 试写一章 → 生成全书 → 审校优化 → 导出交付。**

这样既能发挥 AI 的速度，也能保证大纲、资料和正文之间有清晰关系。
