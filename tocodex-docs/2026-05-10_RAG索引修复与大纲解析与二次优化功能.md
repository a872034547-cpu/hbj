# 2026-05-10 RAG索引修复、大纲解析修复、二次优化功能

## 概要

本次修改完成了三个关键修复和一个新功能：

1. **RAG索引修复**：支持 custom_openai embedding 提供商，OpenAI/custom 初始化失败时自动降级到本地 sentence-transformers
2. **大纲解析修复**：`ch_pattern` 正则从 `\s*[：:\s]\s*` 改为 `\s*[：:]*\s*`，支持"第一章智慧城市"（无分隔符）格式
3. **二次优化功能**：新增"二次优化"按钮、对话框、后台逻辑和提示词规则块

## 修改文件

| 文件 | 修改内容 |
|------|----------|
| `libriscribe/src/libriscribe/rag/embeddings.py` | 重写：支持 openai/custom_openai/local 三种提供商，初始化失败自动降级到本地模型 |
| `libriscribe/src/libriscribe/web/app.py` | 1) 大纲解析正则修复（ch_pattern 支持无分隔符）；2) RAG 索引自动降级到本地 embedding；3) 编辑器页面增加"二次优化"按钮和对话框；4) 新增 `_optimize_chapter_with_ai` 函数 |
| `libriscribe/src/libriscribe/utils/academic_prompt.py` | 增加第六节"二次优化规则"：只修改用户指定部分、输出格式【优化结果】、同样遵守所有强制规范 |
| `libriscribe/src/libriscribe/web/i18n.py` | 中英文新增二次优化相关翻译（optimize_chapter、optimize_title、optimize_desc 等 15 个键） |
