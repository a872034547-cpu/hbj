# 本地依赖安装与服务启动记录

## 摘要

已在本地 Windows/Python 3.8.6 环境中完成好编辑/Libriscribe Web 服务启动所需核心依赖安装，并启动 Streamlit 服务。

启动地址：`http://127.0.0.1:8501`

## 处理过程

- 发现 `pip` 受 Windows 系统代理 `127.0.0.1:7890` 影响，导致联网安装失败。
- 通过 `NO_PROXY=*` 与清华 PyPI 镜像绕过不可用代理后完成核心依赖安装。
- 因当前 Python 为 3.8.6，`unstructured>=0.15.0` 与 `langgraph` 在该环境下不可用/不可解析，因此未按完整 `requirements.txt` 安装这两个不兼容依赖。
- 已安装并验证 Web 启动所需核心依赖，包括 `streamlit`、`openai`、`pydantic`、`chromadb`、`python-docx`、`reportlab`、`python-pptx`、`tavily-python` 等。
- 已用 `python -m streamlit` 启动，避免 `streamlit.exe` 不在 PATH 的问题。

## 为兼容 Python 3.8 做的代码调整

Python 3.8 不支持直接运行时求值 `list[str]`、`dict[str, ...]`、`tuple[...]` 这类内置泛型标注。为保证当前本地环境能导入并启动 Web 应用，给相关入口文件加入了 `from __future__ import annotations`。

## 启动命令

```cmd
set PYTHONPATH=src& set NO_PROXY=*& set no_proxy=*& python -m streamlit run src/libriscribe/web/app.py --server.address 127.0.0.1 --server.port 8501
```
