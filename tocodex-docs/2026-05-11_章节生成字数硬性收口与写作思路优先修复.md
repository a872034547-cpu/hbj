# 章节生成移除强制截断与段落硬规则修复

## 摘要

本次继续修复“写章节”小节生成链路：根据最新反馈，彻底移除所有按目标字数对正文尾部进行强制截断、强制断句或确定性裁剪的逻辑。章节正文即使超过建议字数，也保持完整输出，不再为了贴近目标字数删除结尾论证。

当前策略：

- 不再为了精确贴近目标字数而截断半句话、删除尾句或裁剪论证单元。
- 不再调用 `_trim_to_target_words()`；最终格式化只做标题清理、段落重组和首行缩进。
- 如果模型明显超写，仅记录日志并保持正文完整；长度主要由 token 预算、提示词和模型自身控制。
- 每个小节最多 3 个自然段。
- 可切分时每段不少于 5 句，避免三四句话短段。
- 段落内部不允许空行，只有段与段之间保留一个空行。
- 每个正文自然段首行保留两个全角空格，修复 `str.strip()` 剥离全角首行缩进的问题。

## 变更内容

- 移除最终阶段的字符级硬截断兜底，不再调用 `_hard_clamp_by_count`。
- 移除 `_trim_to_target_words()` 以及所有 `hard_max` 调用路径。
- `_finalize_section_content()` 改为格式规范函数：清理重复标题、重组段落、保留全角首行缩进，不按字数裁剪正文。
- 小节正文超过建议上限时仅写入日志，不再触发确定性压缩或尾部删除。
- `_compress_to_target_words()` 保留为可用的模型改写工具，但不再作为主流程强制调用，也不再包含任何确定性裁剪兜底。
- `_enforce_paragraph_shape()` 保持确定性段落重组：最多 3 段，段内无空行，能切分时每段不少于 5 句且尽量均衡。
- `_ensure_fullwidth_paragraph_indent()` 保证所有正文段落以两个全角空格开头，并避免使用会剥离全角空格的默认 `strip()`。
- 回归测试更新为校验：超字数正文保留完整尾部、不强制压缩、不裁剪、首段缩进、最多 3 段、无段内空行、无短段。
