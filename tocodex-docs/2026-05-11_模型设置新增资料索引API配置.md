# 模型设置新增资料索引 API 配置

## 摘要

本次更新在模型设置页新增独立的“资料索引 API 配置”，用于上传资料时建立向量索引。资料索引现在可以单独配置 OpenAI-compatible `/embeddings` 接口，例如 DeepSeek 的 embedding API，不再必须复用正文写作模型，也不会自动转向 HuggingFace 下载本地 embedding 模型。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 在 `render_ai_config_page()` 的模型档案表单中新增“资料索引 API 配置”。
  - 新增字段：`embedding_api_base`、`embedding_api_key`、`embedding_model`。
  - 保存模型档案时持久化资料索引 API 配置，并支持编辑已有档案时留空保留已保存的索引密钥。
  - 更新 `_embedding_provider_from_project_profile()`，向量索引优先使用独立资料索引配置；未单独配置时才兼容旧的普通模型 API 字段。
  - 独立资料索引配置统一按 OpenAI-compatible embedding provider 调用，适配 `https://api.deepseek.com/v1` + `DeepSeek-V4-Flash` 这类 `/embeddings` 接口。

- `libriscribe/tests/test_commercial_routes.py`
  - 补充模型设置页源码测试，确保资料索引 API 字段、组件 key 和保存字段存在。
  - 更新向量索引 provider 测试，验证独立 DeepSeek embedding 配置优先于正文模型配置。
