# 章节写作重启、标题清洗与反幻觉引用修复

## 摘要

本次继续围绕章节 AI 写作商用稳定性进行修复和验证。已重启 Streamlit，使最新章节写作逻辑生效；修复大纲解析把“（约2000字）”中的“约”和括号残留进小节标题的问题；取消系统自动伪造参考文献模板，改为只有项目中存在真实 citation 记录时才生成参考文献，否则输出“待补充”提示，避免文献幻觉。

## 已完成

- 重启 Streamlit，加载最新章节写作逻辑和 `fileWatcherType = "none"` 配置。
- 验证自定义 OpenAI 兼容模型 raw HTTP 生成通道可用。
- 验证自定义模型 `stream_content()` 已降级复用 `generate_content()`，不再走 SDK 流式阻断路径。
- 修复大纲解析标题清洗：`（约2000字）`、`(总字数 8000字)` 等只进入字数，不进入标题。
- 修复章末参考文献：删除“相关研究者/学术数据库资料/行业研究机构/国际标准化组织”等模板伪文献。
- 强化章节写作提示词：无真实 RAG/citation 来源时禁止输出 `[1]` 式引用、作者、年份、书名、报告名。
- 降低 RAG 缺失时的噪声：未安装 `chromadb` 时不再触发本地 embedding 加载。
- 语法检查通过：`app.py`、`llm_client.py`、`chapter_writer.py`。
- 解析烟测通过：`6.1 制造业绿色转型绩效评价体系构建（约2000字）` 被正确解析为标题 `制造业绿色转型绩效评价体系构建`，字数 `2000`。
- 参考文献烟测通过：无 citation 时不再出现伪造文献，输出“待补充”。

## 修改文件

- `libriscribe/src/libriscribe/web/app.py`
  - 增加 `_clean_outline_title()`。
  - 扩展字数正则，支持并清理“约”。
  - 章节和小节标题均使用统一清洗函数。

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - RAG 检索前先检查 `chromadb` 是否安装，缺失则直接跳过。
  - 强化写作提示词，禁止无来源引用。
  - 删除模板化伪参考文献。
  - 章末参考文献只使用真实 citation；无真实来源时输出待补充说明。

- `libriscribe/.streamlit/config.toml`
  - 将 `fileWatcherType` 调整为 `none`，避免 Streamlit watcher 扫描 `transformers` 导致 `torchvision` 缺失噪声。

```bash
python -c "import sys; sys.path.insert(0,'src'); from libriscribe.knowledge_base import ProjectKnowledgeBase; from libriscribe.web.app import _parse_outline_text; sample='第六章 绿色转型绩效评价与治理体系（总字数 10000字）\n6.1 制造业绿色转型绩效评价体系构建（约2000字）\n6.1.1 碳减排绩效、资源效率、创新能力与经济效益评价指标（约1200字）\n6.1.2 企业、行业、区域多尺度评价方法与数据支撑（约800字）'; p=ProjectKnowledgeBase(project_name='smoke', title='smoke'); c=_parse_outline_text(p,sample,persist=False,rerun=False,show_messages=False); print('parse_count=',c); [print(s.section_number, s.title, s.word_count) for s in p.chapters[6].sections]"
```

