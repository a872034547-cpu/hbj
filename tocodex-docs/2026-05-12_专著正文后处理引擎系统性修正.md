# 专著正文后处理引擎系统性修正

## 变更摘要

本次围绕“AI 负责内容创作，系统负责数字判断、格式校验和流程控制”的原则，修正专著正文生成链路：

- 清理正文生成提示词中的不可靠数字自控要求，避免要求模型自行统计字数、控制段落数量或维持段落/小节长度均衡。
- 新增节奏系数字数分配，按小节标题语义打破机械平均篇幅。
- 新增双引号密度检测与一次定向改写，普通判断句和概念句尽量改为无引号转述。
- 新增字数修正闭环，系统统计汉字数，并在 ±10% 外最多执行两轮补写或压缩。
- 替换旧的硬性分段逻辑为安全分段策略，只在完整句边界和明确语义转折处插入空行，短文本或无安全断点时保持原段落。
- 同步更新章节写作模板与全局学术提示词，统一段落、引号、篇幅控制原则。

## 修改文件

- `libriscribe/src/libriscribe/agents/chapter_writer.py`
  - 新增/接入 `distribute_word_targets()`、`check_and_rewrite_quotes()`、`_repair_word_count_loop()`、`enforce_paragraph_shape()`。
  - 主流程按“引号检测与重写 → 字数补写/压缩闭环 → 质量门禁 → 再检测修正 → 断尾补全 → 安全分段与缩进清理”的顺序处理。
  - `_count_words()` 改为仅统计汉字。
  - 删除旧的按目标字数硬切段逻辑。

- `libriscribe/prompts/templates/chapter_writer.yml`
  - 删除模型输出评分表、自检、硬性字数偏差控制等要求。
  - 增加少用双引号、自然分段、不追求段落长度整齐、不输出过程说明等行为约束。

- `libriscribe/src/libriscribe/utils/academic_prompt.py`
  - 同步更新全局学术专著系统提示词中的段落规范、引号规范和篇幅控制原则。
