# 资料管理与自定义引用功能补充

## 摘要

本次补充了资料库的查看与删除能力，并在引用与事实核验中心增加自定义添加引用文献入口。资料删除会同步移除对应证据片段，但不会自动删除用户已整理的引用记录。手动添加的引用默认进入未核验状态，后续可继续补充 DOI、URL 或页码完成核验。

同时更新了用户说明书，并补充测试覆盖资料查看/删除、自定义引用添加以及独立资料索引 API 配置相关逻辑。

## 变更文件

- `libriscribe/src/libriscribe/web/app.py`
  - 新增资料删除辅助函数。
  - 在资料页“已索引资料”区域增加资料详情查看与删除按钮。
  - 在引用页增加“自定义添加一条引用文献”表单。
  - 保持资料索引 API 与模型档案互不影响。
- `libriscribe/tests/test_commercial_routes.py`
  - 增加资料删除行为测试。
  - 增加资料页查看/删除 UI 断言。
  - 增加自定义引用添加 UI 与未核验状态断言。
- `tocodex-docs/2026-05-11_用户说明书-资料索引API独立配置与使用教程.md`
  - 补充资料查看、资料删除、自定义引用添加与未核验说明。
